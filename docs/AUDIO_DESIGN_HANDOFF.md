## 1. 聲音歸屬與設定

沿用現有設定，不新增 UI：

- **環境音**滑桿：柴火、風、水、草、雨、布料、木頭、腳步、鳥鳴，以及提燈點亮時的「火焰一旺」。
- **背景音**滑桿：和弦墊、提燈單音、取得核心與真結局的旋律。背景音為 0 時這些都不播。
- **全部靜音**：全部不播，保留兩個音量值（沿用現狀）。
- 所有聲音維持原創 Web Audio 合成；唯一例外是階段 5 的鳥鳴，沿用已有的 CC0 檔 `src/renderer/src/cloudRuins/audio/birds-isaiah658.ogg`，授權說明沿用 `cloudRuins/audio/CREDITS.md`（若移到共用資料夾，CREDITS 一併移並更新路徑）。
- 聲音只是呈現層：不決定計時、事件、獎勵或存檔；音訊建立失敗不得阻止場景或專注。

### 聲音語法與預算（全遊戲通用）

每個聲音只有三種存在理由：**空間**（這裡是哪裡）、**狀態**（這件東西現在怎樣）、**回饋**（你剛做的事發生了）。沒有理由的聲音不做；沉默也是設計。

- **單音 = 小發現**：提燈點亮（C4）、旅程信物取得、線索桌兩條線交會（G4）、燈柱看懂的那一瞬間。
- **旋律 = 大時刻**：只有取得核心、真結局、十件齊聯動。
- 同一個畫面裡，前景聲音最多同時 3 個，另加一層很安靜的底噪；事件回饋與旋律播放時，其他聲音在約 0.3 秒內壓到約 30%，結束後約 1 秒回復。

## 2. 和弦墊（所有場景統一）

- 調：Csus2，音高沿用現有的 C3 / G3（195.998 Hz）/ C4 / D4（293.665 Hz）。提燈單音與旋律都以這個調為中心。
- 曲線不一致：雲上遺庭用線性（`value/100`），苔痕驛站與營火用 1.4 次方。統一用 **1.4 次方**。
- 壓低：設計目標是「環境音 35% 時，背景音拉到 100%，和弦墊仍比最弱的環境層（遠處水聲）更小聲」。預設背景音 12% 時應該幾乎聽不出來。實際增益以試聽為準，不要求我給精確值。
- 營火大廳原本沒有和弦墊；加上同一層，由背景音滑桿控制，音量規格同上。
- 收藏室與旅途中的大廳也用同一層；§3 的單音、§9 的單音與「看懂」的音高對準，都以這個調為準。
- 建議把和弦墊、曲線與單音／旋律的合成函式抽成共用模組（例如 `src/renderer/src/audio/`），三個場景共用；結構由 Codex 決定。

## 9. 收藏室（行李內部）

收藏室目前完全無聲；從大廳切到收藏室時，既有的大廳聲音會淡出並 suspend。以下是設計；實作由 Codex 負責。收藏室的場景、錨點與演出以 `COLLECTION_ROOM_HANDOFF.md` 為準，聲音不改變任何已驗收的畫面與規則。

### 9.1 原則

套用 §1 的聲音語法與預算。收藏室是行李裡的小空間，整體比營火與各張地圖都更安靜。全景時持續發聲的核心最多 3 件（05、09、06 的氣流）；點開某件核心特寫時，那件拉到前景（約 +6 dB），其他壓到約 50%。整個收藏室最大聲的時刻只有一次：十件齊聯動。

### 9.2 房間底噪

- 行李內部的室內空氣：帆布內襯的柔和低頻，很小聲、沒有明顯節奏。走環境音滑桿。
- 蠟燭**不發聲**：火聲留給營火，讓營火是全遊戲唯一的火聲。
- 和弦墊同 §2，走背景音滑桿。

### 9.5 進出收藏室（通用，不綁營火）

使用者指出：收藏室旅途中隨時可以開，不一定在營火旁，可能在地圖休息處。所以不要寫成「營火聲變悶」，要做成通用規則：

- 大廳聲音（不管是營火還是地圖休息處）整組走同一條「外面」聲道。進入收藏室的 1.2 秒內，這條聲道先做低通（約 500–700 Hz）並降到約 15%，之後不要完全關掉，保留約 5–8% 的悶聲留在房間底噪裡，當作「包口外面的世界」。這樣在苔痕驛站下雨時，房間裡會有帆布上的低沉雨聲；在營火旁會有極遠的火聲，不用另外做資料。
- 包口打開：帆布與銅扣輕響一聲（約 0.2–0.6 秒），房間底噪在 0.6–1.2 秒升起。離開時反過來，約 1 秒。
- 現在「切到收藏室就淡出並 suspend」要改成「低通降音，保留一點」，離開時恢復；仍需遵守靜音、音量 0、最小化的既有行為。

### 9.6 線索桌、筆記、十件齊聯動

- **釘上線索**：紙條落下（以手指碰到的時刻 H 為準）、圖釘「叩」一聲、紅線拉出時有極輕的拉緊聲；兩條方位線交會時一個單音（G4），霧散不另外加聲；浮出地點、「？」不加聲。
- **翻開筆記**：大手翻開時的紙頁聲；閱讀畫面裡翻頁、闔上也是紙聲，很輕。
- **十件齊聯動（約 8 秒，只播一次）**：
  - 0.4–2.2 秒：各機件加速，各核心的聲音一起漸強（藏聲石低鳴變密、鐘面一直走、羅盤針滴答、橋頭燈的點燈聲、號角第一次出現音高、稜鏡的高音閃爍）。
  - 2.2–3.6 秒：光從天穹儀穿出包口時，所有聲音在約 1.4 秒內滑向同一個和弦（Csus2）。
  - 3.8 秒文字出現後：只留和弦長音，其他降下去。
  - 6.0–7.8 秒淡出；8 秒後回到完成狀態：鐘面持續走，其餘回到 §9.1 的預算。
  - 十種音色疊加屬於這裡；這是收藏室唯一允許所有核心同時發聲的時刻。

### 9.7 三個設計點（使用者已確認）

1. **號角平時不響。**蒼鯨號角的音高只在取得、聯動、真結局出現；平時只有氣流呼吸。
2. **「看懂」讓聲音變準。**已放上的核心音色略鈍、音高略不準（約 −15 至 −20 音分）；看懂後音高對準 Csus2，多一個泛音。玩家不用看介面就能聽出差別。
3. **收藏越多，房間越「滿」。**空行李回音尾巴長（約 1.8 秒），十件齊後短（約 0.5 秒），依已放上的核心數平滑變化；放上新核心後約 2 秒內慢慢縮短。回音只用在單音與實體聲上，不拉長環境底噪。

### 9.8 實作注意與檢查

- 聲音由收藏室場景狀態與時間驅動。原型的 `enterBag`、`pinClue` 收尾用 `setTimeout`（真實時間），音效不要跟著用真實計時器。
- 聲音不決定結果：核心是否取得、聯動是否播過，仍以存檔為準；音訊失敗不阻止收藏室。
- 系統開啟「減少動態效果」時，大手與裝飾動畫會縮短或關閉；單音與落位聲是結果回饋，建議保留，省略袖子摩擦聲。
- 建議檢查：背景音為 0 時沒有單音、旋律與和弦墊；環境音為 0 時沒有底噪與核心的機件聲；全景前景聲音不超過 3 個；放上演出只在第一次出現；進出收藏室時大廳聲音是低通降音而不是被切掉，離開後恢復；十件齊聯動只播一次且之後預算回到 §9.1。
- 主觀聽感由使用者決定。

### 11.1 這張地圖的聲音要說什麼
