# 玻璃苗圃專屬動畫音效測試

2026-10-08：依使用者要求新增專屬測試畫面，不必啟動專注計時；使用正式 `glassNurseryScene` 與 44 動作／環境音檔、4 段背景音樂，共 48 音檔。測試窗不載入後端或遊戲資料庫，不改變玩家存檔。

## 開啟

- 桌面捷徑：`玻璃苗圃－動畫音效測試.lnk`。
- 備用啟動：`scripts/open-nursery-audio-tester.cmd`。
- 離線網頁包：`previews/nursery-audio-tester/dist/`；原始畫面 `src/renderer/nursery-tester/`。啟動器以 Electron 開啟離線頁面，不需要伺服器、npm 或另裝工具。

## 可以測什麼

共 22 個按鈕，四組：

| 分組 | 內容 |
| --- | --- |
| 日常動作 | 走路、外圈半圈、擦玻璃、扶盆／撥土、閥門／噴霧、撥水、看池、大樹、坐螺旋梯、空中走道 |
| 故事發現 | 首訪灑空盤、摸刻度、鏡片手印、壓葉標本、護根布、封存種莢完整取得 |
| 照料者 | 種幼苗、完整五段移植 |
| 休息出口 | 上轉盤休息、五燈、連廊門、地窖鐵梯 |

正常速度，可暫停／繼續、重播、靜音、調環境與音樂音量；六種光線／霧預設，含 75 秒濃霧散開。預設直接從動作位置開始，也可勾選從休息處走入。每次切換或重播會重設角色、盆土、鐘罩／掛鎖、小樹及刻度。

核心木琴仍是待確認試聽，僅提供獨立播放器；試聽時凍結場景及其音場，避免重疊。沒有把木琴加入正式核心動畫。

背景音樂依 `AREA_07_AUDIO_PROMPTS.md` §9 間歇播放，進場先留白 20–40 秒。新增 A／B／AB／C 四段獨立播放器、背景音 12%／25% 按鈕、立即聽環境混音，以及「縮短留白至 3 秒」。取消勾選後恢復日間 60–150 秒、夜間 90–180 秒留白；黃昏不開新曲。六種環境與動畫使用正式混音，動作時配樂壓低，核心演出淡出。獨立播放器會凍結場景，切換動畫會停止獨立試聽。

日間實際環境混音 WAV：`previews/nursery-audio-qa/bgm-day-12.wav`、`bgm-day-25.wav`。預設仍為 12%，待使用者比較後決定是否調整；此次沒有重新發行已安裝的 0.6.30。

## 來源與驗證

新增 `testMode` 只由此測試頁開啟。播放介面使用既有 STORY／AMB／rest／depart／lightLamp，沒有重做一套動畫或改寫獎勵規則。測試不廣播保存事件。

測試時改善暫停接續：進行中的動作錄音和音效時鐘一起凍結，繼續後從原位置接續；靜音／換動作仍清除舊聲音。此修正在目前來源及測試頁，尚未重新發行已安裝的 0.6.30。
