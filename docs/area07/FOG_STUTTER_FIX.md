# 07 玻璃苗圃：霧卡頓修正（給 Codex，2026-10-10）

## 問題

使用者回報：玻璃苗圃的霧看起來會卡頓，育苗機附近的小霧最明顯。D9 展示影片也錄到同樣的情形。

## 原因

兩組霧貼圖都是「飄到邊界就瞬間跳回另一端」，而且跳的那一格仍是不透明的，所以畫面會頓一下。

1. **育苗機周圍的小霧**（`glassNurseryScene.js` 第 658 行，`C.machineMist`）：6 片大貼圖以 `time * 0.3` 往上升，用 `% 1.4` 取餘數，到頂端就瞬間掉回底部。6 片錯開，大約每 0.8 秒跳一次。
2. **滿屋子的霧團**（同檔第 1035 行，`CI.mist`）：`b.x`、`b.z` 超過 12.5 時直接減 24，整團霧瞬間移到另一側。12.5 仍在畫面裡（靠鏡頭那一側的地板）。

## 修法

讓貼圖在跳回去之前先淡出，跳完再淡入。位置、速度、數量都不變。

**1. 第 658 行（`C.machineMist`）**

原本：

```js
s.material.color.copy(cur.mistC); s.position.y = 1.4 + ((time * 0.3 + i * 0.37) % 1.4); });
```

改成：

```js
s.material.color.copy(cur.mistC); const mph = ((time * 0.3 + i * 0.37) % 1.4) / 1.4; s.position.y = 1.4 + mph * 1.4; s.material.opacity *= Math.sin(Math.PI * mph); });
```

**2. 第 1035 行（`CI.mist`）**

原本：

```js
if (b.x > 12.5) b.x -= 24; if (b.z > 12.5) b.z -= 24; const br
```

改成：

```js
if (b.x > 12.5) { b.x -= 24; sp.userData.wrapT = time; } if (b.z > 12.5) { b.z -= 24; sp.userData.wrapT = time; } sp.material.opacity *= (1 - smooth(10.0, 12.5, b.x)) * (1 - smooth(10.0, 12.5, b.z)) * (sp.userData.wrapT === undefined ? 1 : smooth(0, 4, time - sp.userData.wrapT));
const br
```

注意：第 2 項的透明度乘法必須在 `apply()` 設定霧團透明度**之後**執行（原型裡這段在 `polishUpdate`，排在 `apply` 之後），否則會被蓋掉。

## 驗證

Claude 已在 D9 影片用的原型副本（`showcase-video/d9/nursery.html`）套用同樣的修改，並用無頭瀏覽器逐格檢查：在晨光狀態跑 30 秒，計算每片霧「單格位移 × 當下透明度」的最大值。

| | 修改前 | 修改後 |
| --- | --- | --- |
| 育苗機小霧 | 0.41 | 0.003 |
| 滿屋霧團 | 2.38 | 0.001 |

修改後只剩正常的緩慢漂移，沒有跳動。

## 範圍

- 只改霧的透明度，不影響燈、獎勵、事件機率或專注時間。
- 其他地圖如果也有「取餘數或減一個常數把貼圖繞回另一端」的寫法（例如雲霧、飄浮物），請一併檢查是否有同樣的跳動，有的話用同樣的淡出／淡入處理，並在回報裡列出改了哪些地方。
- 改完後請先讓使用者在遊戲裡試看玻璃苗圃的夜霧與晨光，再討論其他修正。
