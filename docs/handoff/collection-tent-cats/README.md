# 帳篷收藏室 · 貓咪原型（2026-10-15，Claude）

狀態：待使用者看原型。只是設計原型，不是正式 App 程式；沒有授權 Codex 移植。

## 檔案
- `cat-tent-v1.html`：直接用瀏覽器開（需要網路載入 three.js 0.160.0）。三花貓（02 苔痕驛站那隻）趴在 low-poly 小屋扶手椅上，旁邊是火爐、窗、晾著的襪子、備用尖帽、兩個馬克杯、水壺、番茄計時器。
- `gen_cat.py`：用 SDF 程式化建模貓（marching cubes → 簡化到約 7.2 萬面），同時烘焙每個頂點的毛長、梳毛方向、白／橘／黑花色、AO、頭耳尾呼吸的動作權重，輸出 `cat_data.json`。
- `src.html` + `build.py`：頁面原始碼，`build.py` 把 `cat_data.json` 塞進 HTML。

## 作法
- 毛髮：殼層毛（shell fur），一個 InstancedBufferGeometry 畫 16／32／56 層；毛根在皮膚平面上量距離，兩層毛（護毛＋底絨），遠處自動換成平均覆蓋避免閃爍；alpha-to-coverage + MSAA。光照：Kajiya-Kay 雙高光、毛尖逆光、皮膚（鼻頭、內耳、眼眶）分開處理。
- 眼睛：視差虹膜（虹膜在角膜後）、直立瞳孔、角膜反射火光；眼球會跟著鏡頭。上下眼皮可眨眼。
- 動作：呼吸、頭轉向火爐／鏡頭／四處看、偶爾歪頭、耳朵抽動、尾巴尖慢慢甩、自然眨眼；點貓 → 轉頭看鏡頭＋慢眨眼。
- 動作目前是頂點著色器裡的區域旋轉，不是骨架。正式版要換成綁骨架的模型（Blender），毛髮殼層作法可以沿用。

## 已知限制／待決定
- 胸前長毛在大特寫會看到殼層分層；56 層會好很多。
- 臉部大特寫大約是參考圖七、八成的程度；真正逐根毛、濕潤眼睛的等級要預算渲染。
- 待使用者決定：正式基礎貓模型來源（找可商用綁骨架模型／AI 3D 生成再修／照這個程式模型在 Blender 綁骨架）。

## 第二版（2026-10-15 晚，依使用者回饋與三視圖）
- `cat-tent-v2.html`（`build.py` 現在輸出的檔名仍是 cat-tent-v1.html，交付時改名）。
- 毛：身體改成順著梳向躺下的大撮毛簇（約 6.7mm 一撮，橢圓拉長、往梳向傾斜、邊緣破成細毛），不再一根根做；臉、口鼻、腳掌改成貼皮短密毛＋順向筆觸紋理，只有最外層破成細毛當柔邊；兩頰外側加蓬毛；內耳加白色長耳毛。
- 臉：加額頭前傾、眉骨、較高的頭頂、較窄的臉頰，口鼻與鬍鬚墊往前突、鼻樑隆起、下巴分明；眼睛加大、改琥珀色、加補光反射。
- 花色照三視圖：貓的右半臉黑（正面看在左）、左半臉橘＋眼下小黑斑、白鼻樑、白口鼻與白胸，右耳橘、左耳黑。（座標備註：模型局部 +Z 是貓的右側。）

## 第三版（2026-10-15 晚，依使用者回饋）
- `cat-tent-v3.html`。
- 嘴巴：鼻下人中線＋鬍鬚墊下的 ω 形嘴線，改在畫面像素層畫（不靠頂點），而且那條線上方的毛層會讓開，所以不會被短毛蓋掉；鼻頭加鼻孔。
- 耳朵：耳根往頭骨裡埋 1.2 公分並加大融合，耳朵和頭接起來。
- 眼皮：改成裁切球殼，上眼皮往下、下眼皮往上，眨眼時完全合起；睜眼時眼皮在眼睛外面完全不出現。眼皮不跟著眼球轉，黑臉那側眼皮黑、橘臉那側橘棕，邊緣有深色眼線。
- 眼睛：放大約 10%，琥珀虹膜更亮、下半透光，瞳孔放大偏圓，加兩個跟著觀看方向的反光點和角膜濕潤光，做成水汪汪的大眼。

## 第四版（2026-10-15 深夜，依使用者的正臉多角度參考）
- `cat-tent-v4.html`。
- 眼睛：眼球埋在皮膚下，前面切一個接近圓的杏仁形開口（外眼角只微微上揚），所以睜眼時看不到眼皮、也不像兩顆球貼在臉上；拿掉眉骨，避免兇的表情。眼皮貼著眼球（1.012R）在皮膚底下，眨眼時上下同時往中間收、完全合起，顏色跟周圍毛色一致。

- 鬍鬚：改成往前下方展開。
