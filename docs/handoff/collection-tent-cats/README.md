## 檔案
- `cat-tent-v1.html`：直接用瀏覽器開（需要網路載入 three.js 0.160.0）。三花貓（02 苔痕驛站那隻）趴在 low-poly 小屋扶手椅上，旁邊是火爐、窗、晾著的襪子、備用尖帽、兩個馬克杯、水壺、番茄計時器。
- `gen_cat.py`：用 SDF 程式化建模貓（marching cubes → 簡化到約 7.2 萬面），同時烘焙每個頂點的毛長、梳毛方向、白／橘／黑花色、AO、頭耳尾呼吸的動作權重，輸出 `cat_data.json`。
- `src.html` + `build.py`：頁面原始碼，`build.py` 把 `cat_data.json` 塞進 HTML。

## 作法
- 毛髮：殼層毛（shell fur），一個 InstancedBufferGeometry 畫 16／32／56 層；毛根在皮膚平面上量距離，兩層毛（護毛＋底絨），遠處自動換成平均覆蓋避免閃爍；alpha-to-coverage + MSAA。光照：Kajiya-Kay 雙高光、毛尖逆光、皮膚（鼻頭、內耳、眼眶）分開處理。
- 眼睛：視差虹膜（虹膜在角膜後）、直立瞳孔、角膜反射火光；眼球會跟著鏡頭。上下眼皮可眨眼。
- 動作：呼吸、頭轉向火爐／鏡頭／四處看、偶爾歪頭、耳朵抽動、尾巴尖慢慢甩、自然眨眼；點貓 → 轉頭看鏡頭＋慢眨眼。
- 動作目前是頂點著色器裡的區域旋轉，不是骨架。正式版要換成綁骨架的模型（Blender），毛髮殼層作法可以沿用。

## 已知限制／待決定
- 胸前長毛在大特寫會看到殼層分層；56 層會好很多。
- 臉部大特寫大約是參考圖七、八成的程度；真正逐根毛、濕潤眼睛的等級要預算渲染。
- 待使用者決定：正式基礎貓模型來源（找可商用綁骨架模型／AI 3D 生成再修／照這個程式模型在 Blender 綁骨架）。
