## 1. 苔痕驛站：人物辨識度

**問題**：旅人斗篷 `0x3d4659` 跟陰影裡的草地、山壁、樹幹亮度幾乎一樣，傍晚與夜晚只剩帽子和提燈看得到。

**做法**（不改人物模型與顏色、不加全身光暈）：在旅人「身後」（從鏡頭看過去）的地面加一盞低矮的暖色點光 `travPool`，讓深色斗篷背後永遠有一塊比較亮的地面。

- `PointLight(0xffd3a0, 0, 2.2, 1.4)`，不投影子。建立時就加入場景、之後只改強度，不改燈數（沿用檔案裡「Keep light membership stable」的原則，避免 Windows 上整批重新編譯材質）。
- 位置：旅人位置沿鏡頭水平前向往後 0.6、往上 0.4。
- 強度：`(0.45 + 1.2 × min(1.6, cur.lamp)) × lastFade`，約為白天 0.87、傍晚 1.65、夜晚 2.37。白天幾乎看不出來是刻意的。
- 安靜模式（畫面整體變暗）同樣有效，對照圖見 `苔痕驛站_安靜模式_對照.jpg`。

## 2. 玻璃苗圃：光影密度

**原因（技術發現）**：10-04 定的「只有大結構投影子」其實沒有生效。苗圃用 `VSMShadowMap`，而 three r128 的 VSM 會把**所有 `receiveShadow` 的物件也畫進陰影貼圖**（`WebGLShadowMap.renderObject`：`castShadow || (receiveShadow && type === VSMShadowMap)`）。`mesh()` 預設 `receiveShadow = true`，所以 `shadowCasters()` 只把 `castShadow` 關掉沒有用：屋頂拱肋、欄杆、細樹枝、上千片小葉錐、垂藤都還在地上畫線。其他四張圖用 `PCFSoftShadowMap`，沒有這個問題。

**做法**：

- `shadowCasters()` 改寫：用截面粗細判斷「細物件」，不用包圍盒（彎曲的拱肋包圍盒很大，但實際只有 0.1 粗）。
  - `TubeGeometry` 半徑 < 0.13（細鐵件、細樹枝；樹幹與粗根 ≥ 0.28 保留）
  - `ConeGeometry` 半徑 < 0.12（小葉錐、垂藤）
  - `Box`／`Cylinder` 本身截面第二小的邊 < 0.12（**0.14 的鐵框架、柱子與橫梁保留影子**，使用者 2026-10-15 指定）
  - 細物件 `castShadow = false`，且若位置高於地面 0.3 也設 `receiveShadow = false`，這樣才真的離開 VSM 陰影貼圖。貼地的細物件（磚縫、裂紋）繼續接收陰影，不然會在陰影裡發亮。
  - 旅人整組跳過，維持原樣。
- 玻璃有色陰影：霧面 `frost` 0.36 → 0.07（它佔了大半個屋頂，灰色色塊在地上鋪成格子）；藻垢 `algae` 0.34 → 0.24，留作白天唯一的光影特色；`dirt` 0.13 → 0.10。
- 地面 44 塊青苔圓斑改用 `FLOOR_MOSS`（原青苔色往地磚色混 35%），不再像一塊塊貼紙。
- 晨光柱、月光柱、夜霧不動（規則本來就是只有起霧的早晨才有光柱）。

效能：陰影貼圖要畫的物件變少，只會更省。
