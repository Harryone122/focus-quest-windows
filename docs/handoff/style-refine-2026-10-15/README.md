## 1. 原型怎麼看

`docs/prototypes/style-refine-compare.html` 是用 2026-10-15 的正式 `echoQuarryScene.js` 打包出來的，畫面和遊戲一致。上方切換「現在／精緻版」（空白鍵也可以），「分項」可以只開旅人或只開光影材質，「旅人特寫」跟著旅人走。原型中的特寫鏡頭、遮擋物自動隱藏、切換按鈕都**只是看圖用**，不要移植。

原型怎麼接進場景：在場景程式加了兩個鉤子（只在原型的打包副本裡，正式檔沒改）。

```js
// 旅人建好之後（book 那一行後面）
opts.onTraveller?.({ THREE, trav, body, legL, legR, upper, cloak, head, armL, armR, staff, travLamp, lantern, lanternGlow, book, TMAT });
// 第一次 reset/applyLook/draw、CAVE.warm() 之前
opts.onBuilt?.({ THREE, scene, out, renderer, sun, hemi, win: window, TR, setView, getCam });
```

正式版建議改成直接呼叫模組：在同樣兩個位置呼叫 `buildRefinedTraveller(...)` 與 `buildWorldPass(...)`，然後永久開啟（`set(true)`），不保留切換。因為 `echoQuarryScene.js` 由 `scripts/port-echo-quarry.py` 從原型產生，請把這兩處插入一起寫進移植腳本，重新移植時才不會遺失。

## 2. 旅人

做法是**疊加在既有骨架上**：每個骨架節點（`legL`、`legR`、`cloak`、`armL`、`armR`、`head`、`upper`、`staff`）底下掛一組新模型，原本的 mesh 改成空幾何（不刪除、不改 transform）。所以 `POSE`、`poseTraveller()`、握杖同步（§56.8 修的掌心對位 `staffGripOffset`）、坐姿、走路擺動全部照舊運作。

| 部位 | 內容 | 重點數值（骨架座標） |
| --- | --- | --- |
| 斗篷 | 自訂殼面：7 道摺痕往下襬加深，下襬不平、背面長 0.035；內襯在下襬露出；肩上加一層披肩（9 摺） | A 字形：頸 0.045 → 肩 0.098 → 腰 0.112 → 下襬 0.205（原本圓錐底 0.23）。平滑著色 |
| 腰帶 | 皮帶、銅扣、側邊小皮包、左側掛一個小信物（琥珀微光八面體） | 半徑 0.117–0.119，`y = 0.03`（斗篷座標） |
| 腿 | 褲管、三圈綁腿、靴子帶鞋尖與鞋底 | 褲管 0.04→0.035；靴 0.038–0.042 |
| 手 | 鐘形袖、袖口、**戴手套的手**（含拇指） | 袖 0.031→0.045；手套半徑 0.031。原本的手球（含 §56.8 補的右手）一起隱藏 |
| 斗笠 | 車削幾何＋編織紋貼圖（同心環＋細徑向紋，`CanvasTexture`），帽帶、下巴繩，後腦一點頭髮 | 縮放 `(0.9, 0.78, 0.9)`；不畫五官 |
| 圍巾 | 米白 `#e4d9c3`，頸部兩圈，一段搭過毯捲，兩條尾巴從背包後方垂下 | 尾巴由 4／3 節組成，走路時往後揚起 |
| 背包 | 帆布包＋皮革蓋＋銅扣＋前袋、兩條肩帶、紅褐毯捲（兩道綁帶）、側掛錫杯 | 包 0.18×0.23×0.09，中心 `z = -0.16` |
| 手杖 | 微彎的木杖（`TubeGeometry` 沿曲線），三個木節，握把纏布；頂端彎鉤 | 握點仍在 staff 座標 `y = -0.1` |
| 提燈 | 掛在鉤上：吊環、鐵蓋、四根框柱、發光玻璃芯、底座、銅墜 | 燈組縮放 1.45；芯 `emissive 0xffb45e`、強度 1.35 |

燈光：原本的 `lantern`（PointLight）與 `lanternGlow`（光暈 sprite）移到提燈組內的燈芯位置，PointLight 強度 0.8 → 1.0，光暈縮放 0.5（在 1.45 的父層下）。燈的數量不變。

顏色（都是 `MeshStandardMaterial`，硬物 `flatShading`，布料和皮膚平滑）：斗篷 `0x3d4659`（沿用）、披肩 `0x4b566d`、內襯 `0x2a3040`、褲 `0x3a3431`、靴 `0x4e3a2b`、綁腿 `0xb8aa8c`、手套 `0x6b4a35`、帆布 `0x8a7a5e`、皮革 `0x6e5039`、毯捲 `0x8e5a45`、木 `0x7d624a`、鐵 `0x34353a`、銅 `0x9a7a45`、錫 `0x8d9196`。

逐幀動作（原型的 `tick(dt)`）：

- 圍巾尾巴：用旅人位置變化估算走速，走路時往後揚起並加快擺動，站著時只有微風。
- 提燈：阻尼單擺，始終往世界座標的正下方垂，走路時每步輕推。
- **重要**：原型是用畫面時間（rAF）驅動。正式版必須接在 `update(dt)` 裡 `poseTraveller(dt)` 後面，用場景的 `dt`。暫停模式整個世界凍結時圍巾和提燈也要停，倍速與低幀率補算時要跟著走。

## 3. 光影材質（只套戶外 `out` 群組）

在場景建好、導航與障礙物資料算完之後執行一次，不影響路線、`OB`、`chimeBars` 這類在建構時讀 `geometry.type` 的資料。

1. **邊緣光**：所有不透明的 `MeshStandardMaterial` 用 `onBeforeCompile` 在 `gl_FragColor = vec4( outgoingLight, diffuseColor.a );` 前加一段（r128 沒有 `output_fragment` chunk）：
   - `fresnel = pow(1 - dot(normal, viewDir), 2.6)`，正交鏡頭 `viewDir = (0,0,1)`。
   - 乘上朝陽程度 `smoothstep(-0.35, 0.55, dot(normal, 太陽方向（視角空間）))`、太陽顏色 × `min(1.2, 太陽強度 × 0.45)`、`diffuseColor` × 1.1。
   - 另加天空補光 `0.06 × (normal.y × 0.5 + 0.5) × 霧色 × diffuseColor`。
   - 地形強度 0.25，其他 1。`customProgramCacheKey` 依強度區分。
   - 太陽方向與顏色每幀更新（跟著 `applyLook` 的日夜變化）。
2. **由下往上的漸層**：每個幾何依自身包圍盒高度加頂點色，底部 0.74 → 頂部 1.06（smoothstep），材質開 `vertexColors`。共用同一材質的 mesh 都要有 `color` 屬性。已經使用頂點色的材質（地形、洞口）不動；`InstancedMesh`（落葉、屋椽）、透明、加法混合、自發光材質跳過。
3. **倒角**：不透明、無貼圖的 `BoxGeometry`（最短邊 ≥ 0.03）換成倒角方塊，倒角 = `min(0.045, 最短邊 × 0.14)`，依尺寸快取共用。倒角方塊自帶漸層頂點色。原型取代了約 730 個。
4. **地面變安靜**：地形與外圈地形兩個網格，依位置焊接算平滑法線，再按每個三角面的陡度混合：`w = smoothstep(0.3, 0.72, |面法線.y|) × 0.92`，平地用平滑法線、近乎垂直的崖壁保留稜面；材質 `flatShading = false`。遠景山脊坡度大，所以仍有稜面，**這是刻意保留**（使用者還沒要求處理）。
5. **接觸陰影**：用場景既有的障礙物清單（`window.__obst`）把地形頂點色在物件周圍壓暗最多 30%（`1 - smoothstep(r × 0.6, r × 1.9 + 0.25, 距離)`）。
6. **樹冠**：樹的 `Icosahedron`／`Dodecahedron`／`Cone` 幾何改成非索引的副本，法線 = 面法線 45% ＋ 從中心向外 55%，保留輪廓但面與面的明暗跳動變小；另加 0.78 → 1.08 的漸層；材質複製一份改成平滑著色。原型處理了 221 個。
7. **太陽陰影**：`sun.shadow.radius` 改為 3（邊緣稍柔）。

## 6. 驗收與檢查

- **給使用者的試玩入口**：比照 `scripts/try-nursery.cmd`；`.cmd` 用 CRLF。
- **畫面**：日、暮、夜各一張，旅人近景各一張，和本資料夾的對照圖比對。
- **安靜模式**（§55）：邊緣光和天空補光會讓畫面亮一點。安靜／現場兩種模式各截一張，確認安靜模式仍然夠暗；不夠暗就把邊緣光乘上安靜模式的暗化係數。
- **效能**：新增的材質變體要在 `CAVE.warm()`／`compileAsync` 預熱之前就建立，避免 Windows 第一次出現時才編譯造成卡頓（0.6.26 的經驗）。倒角共用快取；樹冠和地形只多一份法線。
- **碰撞**：身體寬度和原本差不多，但多了袖口、背包側掛的錫杯和背後的圍巾尾巴。跑一次既有的淨空檢查（`scripts/qa-echo-quarry.cjs`、`docs/area05/qa/`），特別是洞內窄路和吊橋；手杖與帽沿的接觸沿用 §56.8 的 `qa-cloud-grip` 類取樣。
- **低幀率與暫停**：5 fps 全程跑一次，圍巾與提燈不能抖或跳；暫停時停住。

### 接線與工程處理

- 將設計原始碼移植到共用正式 `styleRefine.js`。五圖與營火主旅人使用同套新造型；苗圃原手杖局部原點以 +0.1 對齊，營火以 +0.54 對齊，保留原握點／骨架。
- 動作走各場景的有效動畫 dt，使用 1/120 秒子步積分避免 5 fps 的提燈彈簧不穩；暫停不推進。光源保留原場景隸屬，只同步至新燈芯，避免淡出時改變燈數觸發編譯。
- 安全隱藏舊手、靴與模型；支援營火 Group 骨架，並保留苗圃直接掛在左臂上的書本（另加實機斷言）。外套色設定更新新斗篷、袖子與披肩；預設午夜藍保留設計配色。
- 秋谷戶外套用倒角、漸層、邊緣光、地形／樹冠法線與接觸陰影。實機統計：733 個倒角替換、2 個地形、221 個樹冠。先完成導航建構，再建立新材質，最後執行洞內預熱。
