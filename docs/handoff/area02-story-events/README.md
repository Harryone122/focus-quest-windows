## 需要 Codex 實作

### 1. 故事事件（後端排程與保存）

- **開場**：`storyRules.opening`。只有整個遊戲第一次探索選了苔痕驛站時排；線索 `m02_open` 由第一次專注的回顧發放，不等動畫。
- **首訪／第二次**：用線索有沒有拿到判定，比照特殊發現排進燈與燈之間，不和同一次探索的信物、核心排在同一段。雨天版本在出發當下依天氣決定（同炭印紙）。
- **核心事件**：`story_core_newtag` 在擁有裂痕羅盤、且這次探索在取得之後才開始時排；`story_core_ledger08` 等 08 做好再接。
- **信物事件**：每次探索最多一件，照一般事件偽隨機、就近優先。寫這一趟大廳的「新發現」卡片；**第一次發生時另寫一條永久線索**（`m02_wick`、`m02_lens`、`m02_sign`、`m02_sapling`，`clueOnce`），之後只有畫面與卡片。`carry_old_wick` 的 `combo` 在同一次探索也拿到舊荷札時多一句。這類線索不能是隱藏地圖解鎖的唯一來源。
- **世界記憶**：`carvingSeen`、`drawerTagLeft`（布林，跨天保留）。幼苗的布是這一次探索的狀態，不跨天。
- **線索保存**：永久保存。`mentions` 裡的地圖還沒去過時，名稱顯示「？？？」。`n_tag`／`n_rub` 在第一次取得那件信物時發放（晴天道標或雨天住宿簿都算）。

### 2. 故事事件（場景播放）

新物件都在原型 partC 的「story props」一段：燈柱刻字＋青苔墊、漂流的熄燈（東支流越過霧瀑，雨天走西支流經過貨車前）、住宿簿的畫、抽屜裡的新行李牌、地藏小杯的幼苗與包根的布、驛站後方霧裡的塔（常駐，很淡）、站名牌上的拓印紙。

播放方式在 partD 的 `storyUpdate()`：逐段姿勢 `phases`、狀態列 `status`、各效果的進度區間。新增兩個姿勢：`readBook`（站著看筆記）、`lens`（舉鏡片）。

### 3. 防穿模（使用者要求，所有地圖通用）

- **場景物件同步到 `mossStationScene.js`**（見 `prototype.diff`）：
  - 大樹根長度上限，不再橫過鐵軌。
  - 入口棧道坡度上限：`BW_PROF`／`bwProfile`，`boardwalk()` 多一個 `heightAt` 參數，`walkY` 與木板用同一條曲線。
  - 站名牌位置、行李推車位置與縮放、忍草球高度。
  - 第二、第三盞燈的位置（JSON `lamps[].prop`）。
- **節點、路線與 JSON**：已經寫進場景 JSON。
- **長度要重算**：`clipFix.changedEdges` 列出的邊與移動過的節點，長度、via 高度、`lampLegs`、`shelterFromLamp`、`graphDiameterInRain` 是 Claude 用原型曲線量的；請用正式方法重算，並重跑燈期限的 60 種子測試。
  - 路線整體稍長：`lampLegs` 最長一段約 32 單位，雨天網路直徑約 69（原本約 60）。
  - 仍在範圍內，但要確認。
- **建議加成自動測試**：`qa/occ.js` 在原型頁面裡用 BVH 射線掃一遍路網附近的佔用格。`qa/clearance/edgecheck.py` 沿每條邊取樣，列出身體（半徑 0.27）或帽簷（半徑 0.36，高 1.05–1.2）碰到物件的地方。
  - 目前只剩兩處：入口棧道最底端在霧裡、旅人還在淡入；棧橋兩側木樁差 3 公分。
  - 其餘全數通過。

## 使用者決定的內容（摘要）

1. **開場**：燈柱刻字。
2. **首訪線索**：親眼看到熄燈漂走，不用船夫。
3. **首訪／第二次的判定**：有沒有拿過線索。
4. **信物事件**：畫面、這一趟的新發現卡，第一次發生時再留一條永久線索（2026-09-29 再決定，和雲上遺庭一致）。
5. **02 看懂**：取得羅盤後再訪時的新行李牌。
6. **護根布**：單件觸發（Claude 判斷可行，細節等玻璃苗圃）。
7. **新類別**：擁有核心才發生的事件，可以給線索。
8. **防穿模**：旅人不能穿過場景物件，之後所有地圖通用。
