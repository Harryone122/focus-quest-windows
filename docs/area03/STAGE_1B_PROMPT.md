## 修正項目

### 1. 中央石台改成不規則、兩層的石庭（SPEC 2.4）
- 拿掉方正矩形與整齊的方磚，照 2.4 做外形、上下兩層、兩處石階、錯縫的石板、南緣破口、東北缺角、零星缺板與縫隙裡少量的草。
- 地標（斷柱、兩根倒柱、石碑）位置不變，依 2.4 放在上層或下層。
- 五個接點（西、北、東棧道、南踏石、沉階）要接得上。
- 濕度、淺水透底、滿潮時在水下隱約看得出兩層輪廓，都要跟著新形狀正確運作（高度貼圖要重烘）。
- draw calls 不要因此大增：石板合併成少數幾個網格（沿用你的 `mergeUnder`）。

### 2. 退潮時的倒影不要碎
- 目前退潮時松樹、拱門、亭子的倒影被打成像素塊，看起來像壞掉。
- 擾動強度降到目前的約 30%，改用**低頻、平滑**的擾動（像微風吹出的長波紋），讓倒影能一眼認出是什麼，只有邊緣輕輕晃。
- 確認倒影貼圖用線性過濾（`LinearFilter`），不要出現最近點取樣的方塊。
- 滿潮維持現在幾乎靜止的鏡面；石環內仍然完全靜止。

### 3. 推近時提高倒影解析度
倒影 render target 的大小改成「畫布 × 0.5 × min(2, zoom)」，`zoom` 改變時重建或 `setSize`。一般全圖維持一半解析度。

### 4. 黃昏改成上紫下橘
黃昏時，薄霞帶從畫面上方約 20% 加寬到約 45%，顏色 `skyHaze` 紫色在上、`skyTop` 橘色只留在畫面下半，中間平順過渡。其他時段不變。
