# 第 1 段回報：湖面、倒影、地形、地標、潮位與日夜

實作者：Sonnet　／　產出：`docs/prototypes/reflection-lake.html`、`previews/area03-stage-1/` 20 張截圖、本檔
旅人依指示只站在原位（TRAV_HOME u=-0.8, v=0.6），沒有走路、沒有燈、沒有互動。

## 1. 做了什麼

- 以苔痕驛站的原型當骨架（相機、UI 列、旅人模型、時段切換、拖曳偷看、`?qa=1` 測試模式），把場景整個換掉：
  - **湖面**：平面反射（鏡像正交相機 + 裁切平面 + 半解析度多重取樣 RT + 紋理矩陣），水面 shader 內建程序天空、雲、星星、漣漪、淺水透底（預烘高度／顏色圖）、岸邊濕線。
  - **地形與五處地標**：蘆葦洲（泥灘、10 格水位標尺、擱淺小船、5 叢會搖的蘆葦）、中央石台（斷柱、倒臥石柱、石碑、沉階）、半沉亭（六角亭、地板東南楔形沉下、傾斜 −4°、長凳、石桌、破鏡框）、松岩（老松會微擺）、石環小洲（盆地＋14 顆環石）。另有左側入口踏石、石拱門（出口 A）、右側長踏石串（出口 B）、棧道與橋墩。
  - **潮位**：純函式 `tideAt(seed, sec)`，事件由種子決定；退潮／漲／滿潮／退；潮位 0～0.30；岩石濕深色再慢慢變乾（DRY_S=240 秒）。
  - **日夜**：600 秒循環（晨 0、晝 150、暮 300、夜 450），平滑混合；夜裡有星星。
  - `mergeUnder` 合併靜態網格降低 draw calls。
- 測試 API：`window.__lake`（`setTime / setTide / setSim / advance / focus / drag / render / state / events / tideAt`），僅供 QA。

## 3. 偏離 SPEC 的地方與理由

1. **亭子加了淺木色天花板**：原本從下往上（倒影）看到亭內是一大塊很暗的黑色，倒影像黑洞，加上天花板讓倒影看得到木紋。
2. **雲量與光照微調（超出 SPEC 給的方向值）**：
   - 雲量 `cloudAmt`：白天 0.74、晨 0.64、暮 0.62、夜 0.42（初版雲太少、像一片平塗）。
   - 光照：白天 `sunI 0.72 / hI 0.58`、晨 `sunI 0.70 / hI 0.60`、暮 `sunI 0.85 / hI 0.55`（初版石頭偏奶油白、太亮）。
3. **蘆葦洲外形**：用「主橢圓 + 一個小橢圓」合成，讓小船與標尺落在陸地範圍內（原本會超出島的邊界）。
4. **蘆葦分成 5 個分組**（每組一起搖），draw calls 從 227 降到 167，不影響外觀。
5. **拱門**用 Extrude 形狀並重算開口、拱心石與底座，讓開口比例正確。
6. **`setTide(x)` 的測試 API**：手動設潮位 0.5 時，狀態標籤會顯示「退潮中」（因為手動值是往下走的狀態）；這只影響 QA 截圖上的文字，不影響自然事件的「漲潮中／退潮中」判斷。
7. **UI 列文字沿用驛站的樣式**，「試看漲潮」按鈕在強制潮位後會改成「回到依時間」。

## 4. 最後使用的配色與參數

- 水位：`WL_LOW = 0.0`、`WL_HIGH = 0.30`；潮：上漲 90 秒、滿潮 360 秒、退 90 秒、變乾 240 秒。
- 時段循環 600 秒（晨 0、晝 150、暮 300、夜 450）。
- 天色（skyTop／haze）：白天 `#6fb0e3`／`#d6ebf6`；晨 `#e9c7bd`／`#f6e6da`；暮 `#e79a67`／`#9a86b3`；夜 `#0d1a2f`／`#1e2f4a`。
- 石頭（乾／濕）`#c9c3b6`／`#8f8b81`；泥 `#9d9076`／`#6f6552`；松針 `#3f5e4c`、`#4a6a55`、`#36523f`；樹皮 `#5a4a3c`；亭瓦 `#4e5560`、`#585f6a`。
- 相機：正交、45°／31°；拖曳偏航 ±1.1 rad、俯仰 −0.3～0.5 rad。
- 種子：`20260930`；天光倒影 RT：畫面的一半解析度。

## 5. 待釐清（我沒有自己決定）

1. **黃昏配色**：照 SPEC 用 skyTop `#e79a67`（橘）、haze `#9a86b3`（紫），結果是水面整片橘、只有遠處上緣偏紫。是否要改成「上紫下橘」？
2. **低潮倒影的破碎感**：低潮時漣漪把小物件（松樹、拱門）的倒影打成碎塊（`dusk-low`、`dawn-low` 最明顯）。SPEC 沒有指定漣漪對倒影的扭曲強度，目前是 `uRipple = 1 − 0.88 × 潮位`。要不要把低潮時的強度降一些？
3. **半解析度倒影在特寫時的階梯感**：要維持一半解析度，還是特寫（`focus` 推近）時動態提高？
4. **1280×800 標題說明文字**會壓到入口踏石鏈的一顆石頭（`day-low-1280` 左上）。這是驛站骨架的 UI 位置；要移標題還是接受？
5. 高潮時亭子東側有一根很細的直線（`day-high` 約 x=822，y=410～430），推近後看是破鏡框的邊，不確定是設計還是要拿掉。

## 7. 已知問題

- 低潮時小物件的倒影比較碎（待釐清 2）。
- 半解析度倒影在推近時有階梯感（待釐清 3）。
- 只在 SwiftShader 軟體渲染下實測，沒有量 FPS；draw calls／三角形數量合理，實機效能未量測。
- `?qa=1` 模式不跑 requestAnimationFrame，QA 用；正常開啟不受影響。
