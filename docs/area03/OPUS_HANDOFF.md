## 工作方式

- 讀使用者電腦上的檔案：用 `device_stage_files` 把檔案或截圖複製到工作區，再用 Read 看圖。寫檔用 `device_bash`（heredoc）直接寫進 `docs/area03/`。
- 資料夾是 `C:\Users\User\Documents\game project`，需要時先 `device_request_folder_access`。
- 查 git 狀態時一定加 `GIT_OPTIONAL_LOCKS=0`，否則會在 `.git` 留下鎖檔擋住 Codex。
- Codex 可能正在同一個資料夾工作：你只寫 `docs/area03/` 底下的檔案，不碰企畫書、`src/`、其他原型。
- 每段流程：寫 `STAGE_n_PROMPT.md` → 使用者貼給 Sonnet → Sonnet 交 `STAGE_n_REPORT.md` 與截圖 → 你驗收、寫 `REVIEW_n.md`，並回覆它的「待釐清」→ 需要時寫修正指令。
- 規格有錯就直接改 `SPEC.md`，標日期；使用者新的決定寫進 `DECISIONS.md`。
