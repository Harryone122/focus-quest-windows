## 2. 要移植的內容

1. **湖與天空**：整個畫面到邊緣都是湖；平面倒影（水位面裁切的反射貼圖）、程序天空與雲倒影、四個時段（晨霧／白天／薄暮／夜）。夜裡湖面是映著星空的水，**湖面上沒有月亮**（決定 11）。
2. **潮汐**：水位 0（退潮）到 0.30（滿潮），由 `tideAt(seed, sec)` 決定；滿潮時石台淹在淺水下、旅人涉水，每步一圈漣漪。路網兩種潮位完全一樣（決定 6）。
3. **五盞燈**：依有效時間亮（不是跟著旅人動畫），燈 4 掛在松枝尖、燈 5 掛在亭子南簷。
4. **旅人**：走路、跳踏石、涉水、漲潮時捲褲管、等燈小動作、示範排程器（App 換成正式排程）。
5. **疊月橋（3C）**：滿潮時半圓拱與倒影接成滿月，橋洞裡永遠是滿月的夜（白天柔和），夜退潮細月牙、漲潮漸盈（決定 11、12，SPEC 9.6）。
6. **浮葉小庭（3C）**：睡蓮池，漲潮葉片攤平、花朵錯開時間開。
7. **石環**：`ringStill` 為 1 時環裡的水永遠靜止；取得核心後永久改成 0。
8. **第 4 段**：40 個一般事件、4 個特殊發現（兩種旅程信物＋核心「湖鏡」）、5 種休息、2 個離開、世界記憶（貝殼 ≤ 10、松果 ≤ 6、石凳上的杯子 `cupLeft`、`ringStill`、石碑擦拭到下次滿潮結束）、旅途筆記文字。

## 3. 光看 JSON 看不出來、移植時要照做的規則

### 3.1 全遊戲的畫面規則（SPEC 10.2、11.7.1）
- 預設鏡頭下，旅人在任何站位、事件都要看得到：身體 ≥ 70%、頭和帽子完整（蘆葦、草、燈光不算遮擋）。
- **任何事件、演出、截圖都不准隱藏、裁切、透視場景物件**（例如拿掉亭子屋頂拍裡面）。看不到就換站位。

### 3.2 坐姿與凳子（Opus 2026-10-03）
節點欄位：
- `seat`：坐的面比節點地面高多少（0 表示坐地上）。也用來判斷「水會不會淹到坐的人」：`水位 < 地面 + seat − 0.02` 才能坐。
- `bench: [u, v]`（選填）：坐下時臀部關節的位置。坐下時旅人從站立點挪過去（挪的距離 > 0.22 時腳踏一兩步，只在中段踏），臀部關節正好落在凳面高度（`hip = seat / 1.15 − 0.3`，模型縮放 1.15），腳往前放（`legX` 預設 −1.0）。站起來反過來；要走去別處時**先站起來、回到站立點才開始走**，起身時不原地踏步。
- `benchLeg`（選填）：覆寫坐著時的腿角度（`c_column` 坐地上靠倒柱，用 −1.45 兩腿平伸）。
- 沒有 `bench` 的節點仍是舊坐法（`seat` > 0.1 時整個人抬高 `seat` 再加 0.12）。目前 JSON 裡沒有這種節點了。
- `clearanceNote`（節點與路線上）：QA 的身體圓柱碰到 0.2 高的凳子而得到負值；實際的腿與斗篷量過不會碰到。驗收時把這幾條當作已量過的例外。

目前用到凳子的站位：
| 節點 | 凳子 | 說明 |
| --- | --- | --- |
| `p_seat` | 亭台南緣石凳 u 1.00–1.74、v 9.20–9.36、凳面 0.38 | 所有休息都在這裡；凳面高出滿潮 0.08，坐著是乾的。坐東半邊、轉向西南（面向 (0.42, 8.0)，看疊月橋）。杯子在西半邊 (1.07, 9.28)，凳面上 |
| `leaf_seat` | 浮葉小庭的石板（凳面 0.31） | 只在退潮 |
| `c_column` | 坐地上、背靠倒柱 | `seat` 0 |

### 3.3 手的左右
模型的 `armL`（x = −0.13）其實是**旅人的右手**，手杖在他的左手（x = +0.2）。拿杯子的是右手。所以杯子必須放在他右手那一側（坐在 `p_seat` 時是畫面左邊、凳子西半邊）。移植時如果重新命名骨架，注意不要把這個左右弄反。

### 3.4 第一次休息 `rest_cup_first`（46 秒，進度 0–1）
0–0.12 站著看凳上倒扣的杯子（杯子 `inv`）→ 0.12–0.24 在杯子旁邊坐下 → 0.24–0.36 右手往右後方伸，0.28–0.34 把杯子翻正（`flip`）→ 0.36–0.44 倒茶，0.41 起杯子在手上（`hand`）→ 0.44–0.97 慢慢喝（`drinkSit`）→ 最後放回凳上（`up`）。播完 `cupLeft = true`，之後杯子正放在凳上、開放 `rest_tea`。

### 3.5 離開（固定 5 秒）
0–1.3 站起、背行囊、扶帽 → 1.3–2.4 沿路線往出口走 1.5 單位，1.8–2.3 淡出、薄霞圍上來 → 2.5 換到出口節點並淡入 → 之後沿 `departures[].offMap` 的踏石往外走，4.2–5.1 淡出。
踏石段**不是一路跳**：每顆石頭上用正常步伐走（每秒 1.15 單位、腿照常擺），走到石頭遠端邊緣前微蹲，跳過石頭之間的水（時長 0.3 + 0.2 × 距離 秒，弧高 0.12 + 0.1 × 距離，腿收起），落地微沉再繼續走。起跳點與落地點在石頭頂面內 0.13（石頭半徑來自場景裡的踏石）。有水（潮位 > 0.13）時起跳、落地各一圈漣漪。實作見原型 `departPlan` / `departAt`。

### 3.6 核心「湖鏡」
時間軸見 SPEC 11.8 第 5 條（App 時長 80–110 秒）。演出 0.30–0.88 整片湖靜止（`lakeHush`）。鏡中是**真的 3D 倒影**（另一張反射貼圖），不是平面剪影；約 0.85 時旅人轉頭，倒影慢 0.5 秒才轉（記住頭的角度歷史）。反射相機只框住水鏡本身（`mirrorRender`），貼圖是正方形、約等於水鏡在畫面上的像素大小。

### 3.7 其他
- 滿潮版銅片：抽中 `rare_gauge_plate` 時若出發當下是滿潮，改播 `rare_boat_plate`（同一件物品、同一筆保存結果）。
- 每趟探索在第 1–4 盞燈之間必得兩種旅程信物之一；核心每盞燈 5%、第五次保底（保底由 App 做）。原型的抽法只是示範。
- 「白鷺在 A 點」是事件開始前把白鷺叫回 A 點，不是抽選條件。
- 場景裡沒有任何文字或數字（標尺最高刻線旁的刻字是第 5 段的開場故事才露出）。

### 3.8 第 5 段：故事與信物事件（2026-10-03 完成，`REVIEW_5.md`、SPEC 第 12 節）
- 資料在場景 JSON 的 `storyRules`、`storyEvents`（含 `push`、`props`）、`clues`。判定用線索（同苔痕驛站），首訪、二訪一定排在滿潮。
- 首訪的倒影分身：演出期間真的旅人只放主畫面圖層，倒影裡由同一模型的分身代替，只有身體朝向延遲；腳底位置相同。
- 只在倒影的道具放在湖面反射相機專用圖層（第二只杯子與熱氣、靴子、橋頂提燈）。
- 推近：中心 `push.at`、倍數 `push.zoom`（相對於預設全景）、`push.outAt` 起拉回 3 秒；結束或中斷都還原鏡頭。故事事件與信物事件都有（信物事件只推近 2.4–3 倍），開場沒有。
- 旅人一定走到事件地點才開始演出，不瞬移；走路時鏡頭維持全景（`storyRules.approach`）。
- 原型的「鏡頭：跟著旅人」按鈕與 `followCam`、`s5()` 掛鉤只是測試用，App 不用做。

## 7. 移植後的自我驗收

1. 預設鏡頭、1600×900 與 1280×800：五區完整入鏡、畫面四邊都是湖。
2. 退潮／滿潮 × 四個時段，各看一次全景；滿潮夜裡橋洞是滿月、湖面沒有月亮。
3. 五盞燈依有效時間亮：正常播放、加速、跳到完成、暫停、重來都準。
4. 40 個事件、4 個特殊發現、5 種休息、2 個離開都播完一次（原型對照用 `qa/final-audit.cjs`）。
5. 坐姿：`p_seat` 坐在石凳上（退潮、滿潮都乾的）、杯子在他右手邊的凳上；`leaf_seat` 坐在石板上；`c_column` 靠著倒柱坐地上；沒有任何坐姿浮在半空或插進物件。
6. 離開：踏石段是「走、蹲、跳、落地、走」，不是一路跳；滿潮時走在水下的踏石上、每步有漣漪。
7. 核心：鏡中是 3D 倒影、轉頭慢一拍；之後石環的水會起漣漪。
8. 任何時候都沒有隱藏屋頂或其他物件；預設鏡頭看得到旅人（k_lamp4 例外：擋住的是他腳邊隆起的岩面，帽子是完整的）。
9. 繪製次數照第 4 節；沒有 console 錯誤。

原型的 QA 工具都在 `docs/area03/qa/`（`check.js` 路網、`visibility_s4.js` 可見度、`bench-clearance.cjs` 凳子與腿的實際距離、`final-audit.cjs` 全部播一次），用法寫在各檔第一行。
