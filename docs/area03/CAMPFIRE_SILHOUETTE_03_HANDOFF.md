## 2. 設計

- **沒有台地、沒有倒錐**。倒影湖畔的地圖本身是「整片都是湖、沒有邊」，所以剪影只是一片平躺在霧裡的鏡面水（半徑約 5.6、放射狀透明、邊緣再蓋幾團霧），看不到水的邊界。
- 水面上只有三樣東西，全部附上下顛倒的真倒影（複製後 `scale.y = -1`，顏色往水色混 45%，透明度 0.75）：
  1. **疊月橋（視覺重心）**：拱面正對鏡頭，拱的起拱線就在水面上，所以半圓拱加上倒影剛好接成一個完整的圓。圓裡是深藍的夜窗和一個小滿月，對應地圖 §9.6.2「滿潮時橋洞裡是有滿月的夜」。
  2. **半沉亭**：放在左側，往東南傾斜。地圖裡是 4°，這裡加大到約 7°，否則在這個距離看不出來。
  3. **松岩老松**：放在右側，最低一層枝葉往水面伸。
  另外有三顆踏石往右後方延伸，暗示出口 B。
- **故意不放石拱門**：遠看會跟雲上遺庭的半截石拱撞形狀。
- **固定畫滿潮**：營火這裡沒有潮汐時間（使用者決定）。
- 用色：與其他剪影同為低彩度灰。水色每幀由營火的 `skyCur.fog` 往 `#86a0b0` 混 55%，所以會跟著營火階段的天色變。
- **彩蛋：倒影先出現**（使用者批准，扣住地圖主題「倒影似乎比本人多知道一點」）。這條路的霧開始變薄後，用內部計時 `t` 控制：
  - 倒影與水面：`t` 0.3–1.0 秒淡入。
  - 實體：`t` 0.7–1.45 秒淡入，比倒影晚約 0.4 秒。
  - 霧回厚時，以 1.4 倍速倒退淡出。
  - 這是純畫面，不影響路線、Focus、存檔。

## 3. 需要 Codex 做的事

1. **載入剪影**：比照 07／05，用 `?raw` 匯入 `docs/area03/campfire-silhouette-03.html`，取出兩個標記之間的程式碼，插在 `const DEST = {};` 前面。標記以外的 `?sil03` 預覽掛鉤只給原型用，不要移植。
2. **依 mapId 換上**：`__campfireSetDestinations` 加一個分支：`id === 'area-03-reflection-lake'` 時呼叫 `silReflectionLake(d); d.scale.setScalar(.85);`。換成別張地圖時清掉 `d.userData.sil = null`，避免留著舊參考（`alive()` 本身也會擋）。目前選到湖畔時這個位置是空的，因為只有 01、02、07 的分支。
3. **每幀更新**：在營火的 `update(dt)` 裡、`S.hoverT = …` 那行後面加上這一行。它和 05 的那一行是同一行，只多傳第 4 個參數，05 會忽略：
   `['bridge', 'steps'].forEach((k) => { const s = DEST[k].g.userData.sil; if (s && s.alive()) s.update(dt, mt, S.hover === k ? S.hoverT : 0, veilTarget(k) < 0.5); });`
   - `veilTarget` 是原型 `update()` 裡判斷霧要變薄的函式（滑過路線卡，或出發演出前 2.6 秒的已選路線）。如果正式版的位置不同，請傳等義的布林值。03 依它淡入，所以出發時也看得到。
   - 剪影內部會在 `update` 裡讀 `skyCur`，只能從 frame loop 呼叫，不要在建立剪影時呼叫。
   - 要能用 `advance()` 一步步推進，所以不要另外開 `requestAnimationFrame`。
4. **音效**：無。這個剪影沒有發聲事件。
5. **檢查**：
   - 左右兩條路都要看：滑過、離開再滑過、快速滑進滑出（不能卡在半透明）、出發演出。
   - 營火 0–5 階段的天色下，水面都要看得出是水，不能和霧混成一片。
   - 換地圖後，舊剪影的 `update` 不會再跑。
   - 透明排序：倒影 `renderOrder` 1、水面 2、反光 3、實體 4。不能出現倒影浮在水面上、或實體被水面蓋掉。

### 2026-10-13 Codex：雲霧播放／重播卡頓修正
