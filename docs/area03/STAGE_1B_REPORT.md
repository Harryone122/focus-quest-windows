# 第 1 段修正回報

實作者：Sonnet　／　只動了 `docs/prototypes/reflection-lake.html`、`previews/area03-stage-1b/` 10 張截圖、本檔。版面沒有新增任何區域（DECISIONS 第 7 項）。

## 1. 四項修正怎麼改的

1. **中央石庭（SPEC 2.4）**：拿掉方正矩形與棋盤格。外形改成 40 個頂點的不規則多邊形，加上兩層（下層 y=0.12、西北上層 y=0.20）、兩處單階落差（y=0.16）、南緣破口、東北缺角。石板改成錯縫排列、長 0.6–1.6、寬 0.62–0.95 的長方石板；少數深／淺色、翹起（傾斜 1–3°、翹起不超過 3 公分）、細裂縫；零星缺板露出泥面；草與青苔只放在上層邊緣、下層邊緣少量、以及斷柱腳下。高度貼圖已用新形狀重烘，濕度、淺水透底、滿潮的水下輪廓都跟著新形狀運作。
2. **退潮倒影不碎**：漣漪改成低頻長波（波長約 3 倍），位移量降到約 30%（`amp` 0.0034 → 0.0026，再加上頻率降低，實際位移約為原來的 3 成，是估算值、沒有量測）。倒影貼圖本來就是 `LinearFilter`，沒有最近點取樣。滿潮仍是 `uRipple = 1 − 0.88 × 潮位`，石環內仍然完全靜止。
3. **推近時提高倒影解析度**：倒影貼圖大小 = 畫布 × 0.5 × min(2, zoom)，其中 zoom = 全圖視野寬 ÷ 目前視野寬。變化超過 6% 才 `setSize`，避免動畫縮放時每幀重建。全圖維持一半（1600×900 畫布 → 800×450），推近 2 倍時 1600×900。
4. **黃昏上紫下橘**：新增每個時段的 `hazeLo`（晨、晝、夜 0.80，黃昏 0.55），紫色薄霞帶從畫面上方 20% 加寬到 45%，並加了一個小曲線讓紫色在上緣更明顯；其餘時段不變，時段之間會平順混合。

1. **南緣破口中心從 (−0.2,−4.0) 移到約 (0.7,−3.7)**（u −0.1…1.5）。原位置會壓到南踏石接點 (−0.9,−4.5) 的落腳處，與「接點附近要完整」衝突。

4. **上層落差**：上層與下層之間除了兩處單階，其餘邊緣是 8 公分的落差（照 SPEC）。

## 5. 待釐清與已知問題

1. 倒柱在上層的矛盾（見上）；等你決定要移座標還是把上層範圍往東延伸。
2. 破口中心已移動（見上）；如果一定要在 (−0.2,−4.0)，就要把南踏石的接點也往西移。
3. 積水沒做（見上）。
4. 滿潮時兩層的輪廓靠底色差（上層底色稍亮）來表現，只有「隱約」；若要更明顯要再調水底透出比例。
5. 黃昏紫色實際看得清楚的範圍約畫面上緣 30%，再往下是漸層；若要「明確 45%」再加強，需要調 `hazeLo` 曲線。
6. 只在 SwiftShader 軟體渲染下實測，沒量實機 FPS；draw calls 184。
