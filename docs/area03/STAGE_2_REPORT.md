# 第 2 段回報：地標細節與環境生命

實作者：Sonnet　／　只動了 `docs/prototypes/reflection-lake.html`、`previews/area03-stage-2/` 16 張截圖（另附 1 張 `zoom-pavilion-low-default.png` 當對照）、本檔。沒有動 git，場景裡沒有任何文字或數字，旅人仍站在 (−0.8, 0.6)，沒有做燈、路線、事件。

## 1. 做了什麼

**共用潮痕帶**
- 所有會被淹的垂直面（石、木、柱腳、標尺、船身、拱門、石碑、斷柱、松岩）共用同一個 shader 補丁：y 0–0.30 是一致的深色帶，上緣界線清楚；滿潮水面（y = 0.30）正好貼在帶的上緣。潮退後的「濕度」照舊獨立運作。

**地標細節**
- **半沉亭**：屋面瓦壟、六條垂脊、簷角上翹、簷下一圈椽頭、柱腳潮痕、石桌與兩條長凳；南簷掛鉤（懸臂＋吊桿＋鐵環，燈 5 之後掛這裡）；北側欄杆上的空木鏡框，只在左下角卡一小片鏡片，白天偶爾閃一下；落葉、東南角石板縫青苔。
- **水位標尺**：十道刻痕（只有刻痕，沒有數字）、最高線旁留一塊空白石面、頂上有石帽。
- **蘆葦洲**：蘆葦數量與高低層次提高、會擺（風＋滿潮時減弱）；潮池、貝殼、漂流木、船（含撐篙、繩子、船底積水）。
- **石拱門**：拱環、柱腳、線腳、青苔與藤蔓（頂點色）。
- **松岩**：岩面、樹根、地衣、灌木；**燈 4 用的長枝**朝東伸出，只留接點，沒有燈。
- **石庭**：石碑水痕與雨痕、碎石、斷柱與倒柱的碎屑、缺板處的積水。
- **缺板積水**：2 塊只映天空色的平面，不參與倒影、不投影，滿潮時被水面蓋過，沒有突兀方塊。
- **石環**：外圈換成大小不一的自然大石（帶青苔），內圈靜水不變。
- **棧道／踏石**：板縫、缺角、邊緣磨損；沉階做成水下漸層。

**環境生命**（全部走 `tAcc` 動態時鐘；暫停時凍結；「減少動態效果」時速度降到 0.25 倍）
- **白鷺**：低多邊形，站、走、啄、理毛、飛、睡都有；`window.__lake.egret('stand'|'walk'|'peck'|'preen'|'fly'|'sleep')` 可強制切換；夜裡自動睡覺；有倒影，只有身體投影。
- **魚跳**：偶爾一次，水面有水花與漣漪；**潮池魚影**：退潮後的潮池裡有小魚影游動。
- **蜻蜓**（白天）：翅膀單一網格，兩隻，低頻。
- **螢火蟲**（夜）：單一 Points，倒影裡也看得到。
- **水面閃光**：shader 內做，白天強、晨昏弱、夜裡關；推近時做了縮放補償，不會變成大光斑。
- **風**：全場共用一個值，蘆葦、樹冠、藤蔓共用。

## 3. 和 SPEC 不同的地方，以及接點座標

**接點實際座標（(u, v, y)，世界座標由 `__lake.W(u,v,y)` 換算）**
- **燈 4 長枝枝尖**：(8.70, 1.30, y 2.00)
- **燈 5 掛鉤（鐵環中心）**：(2.076, 9.052, y 1.594)
- 兩者都是從實際網格量出來的（`__lake.marks()`），不是估計值。

**不同之處**
1. **鏡框位置與顏色**：SPEC 只說「北側欄杆上」。從預設鏡頭看，北側是遠側，鏡框被前簷和柱子擋住。我把它放在欄杆正中偏西（local x −0.3、y 1.2），並把木色從深木改成較淺的舊木色，這樣在低俯角（約 13°）能看到；預設 31° 視角仍只看得到鏡片閃光和一小段框。要不要為了預設視角可見而改到別的欄杆，請你決定。
2. **減少動態效果**：做成降到 0.25 倍，不是完全停止（SPEC 寫「降低或停止」）。
3. **積水只做 2 塊**（座標 (2.69, −0.54)、(4.45, −0.54)），對應第 1 段留下的缺板；其餘缺板仍只露泥面。
4. **水位標尺低潮時下半被泥面蓋住**，潮痕帶在低潮看不全；滿潮截圖才看得到整段。

## 6. 已知問題

- 只在 SwiftShader 軟體渲染下實測，沒有量實機 FPS。
- 白鷺飛行在強制切換潮位時會被打斷（QA 現象，正常遊戲流程不會遇到）。
- 鏡片閃光的星芒在近拍時偏大；平常只閃約一秒。
- 標尺、蘆葦洲等處的細節在預設全圖視角下很小，主要靠推近才看得清楚。
