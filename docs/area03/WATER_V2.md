## 1. 五項效果

| # | 名稱 | 看起來 | 什麼時候 |
| --- | --- | --- | --- |
| 1 | **波光粼粼**（取代舊的隨機亮點） | 亮點長在三組交錯小波的浪峰上，跟著波浪出生、滑一小段、消失；外面包一層柔和的浪峰微光，形成一條「光路」。亮點是沿螢幕水平的短橫條（不是圓點），成群漂移，不平均灑。顏色跟太陽：白天暖白、晨霧粉金、薄暮金橘 | 只在原本的太陽方位窄帶（SPEC 2.5、REVIEW_2），帶子加寬一點、外側加一圈較淡的範圍、長度 16–24。夜裡沒有。滿潮時亮點更細更稀（鏡面），不會變成整齊點陣 |
| 2 | **貓掌風**（陣風掠過水面） | 一塊橢圓形、前緣較銳利的區域從蘆葦洲那側順風飄過湖面約 9–13 秒；裡面出現細碎波紋、倒影被打散、水色略暗 10%，經過太陽光帶時波光變亮。陣風經過蘆葦洲時蘆葦擺幅加大，經過松岩時松枝跟著擺 | 動態時間每 25–50 秒一次。滿潮時強度約 55%；故事 `lakeHush` 期間不出現；減少動態效果時完全不出現；石環靜止遮罩照舊 |
| 3 | **岸邊細浪** | 兩道細亮線沿著水位線慢慢爬上岸再淡掉，沿岸錯開節奏，留下一點濕亮 | 所有時段；滿潮時減半；遠處水面淡出避免鋸齒 |
| 4 | **水底光紋** | 淺水下的石面與泥地上有一張緩慢移動的陽光網紋，顏色跟太陽 | 只在白天／晨霧／薄暮（跟 `glint` 值）。滿潮淹過的石台上最明顯（天空之境底下的光），深度 0.45 以上看不到 |

## 2. 原型裡的實作位置（給 Codex 對照移植）

正式場景與原型幾乎逐行對應，移植時照下列片段搬：

1. **Shader**（`FRAG` 陣列，搜尋 `water v2`）：
   - 新 uniforms：`uGust`（中心 u、v、方向角、強度）、`uGustR`（3.4, 1.9）、`uSunCol`、`uWind`、`uWaterFx`、`uLampK`、`uLampS[5]`、`uScrU`。
   - 貓掌風：緊接 `rip *= amp;` 之後；水色變暗在 `gl_FragColor` 前。
   - 水底光紋：`bot` 計算之後的 `caus` 區塊，加在 `col = mix(col, bot, kk);` 之後。
   - 岸邊細浪：靜態 `edge` 線之後。
   - 波光：原 glint 程式保留給 `uWaterFx = 0`（舊版比較），`else` 分支是新版。
   - 燈影：波光之後的 `uLampS` 迴圈。
2. **JS**：`waterFxUpdate()`（在 `update()` 最後、`placeCamera()` 之後呼叫），負責陣風排程、蘆葦／松樹風力（`WFX.reedK`、`WFX.pineK`）、`uSunCol`、`uScrU`（螢幕右方在湖面 u/v 的方向），以及把 `LAMPFX.pos` 的燈火位置以水面鏡射（`y → 2·WL − y`）投影到螢幕像素。`uLampS.w` 是每單位像素數；正式 App 若畫布有 DPR 縮放，請用 drawing buffer 尺寸（與 `uRes` 相同）。
3. **只在原型**：`?water=old`、「水面：新版／舊版」與「試看陣風」按鈕。不要移植到 App。正式 App 只保留新版（`uWaterFx = 1`）。

## 3. 調整參數（使用者若覺得太多／太少）

| 想要 | 改這裡 |
| --- | --- |
| 波光更多／更少 | `spark = pow(crest, 12.0 + 12.0 * uTide) * 4.0`：指數越大越稀；`4.0` 是亮度。成群程度：`clump` 的 `smoothstep(0.35, 0.8, …)` |
| 光帶更寬 | `gb2` 的 `smoothstep(2.0, 0.6, abs(perp))` 與外圈 `0.45 * smoothstep(4.2, 1.6, …)` |
| 陣風更常／更明顯 | `waterFxUpdate()` 的 `25 + Math.random() * 25` 秒；shader 的 `rip * (1.0 + 2.6 * gust)`、`0.0036`、變暗 `0.10` |
| 岸邊細浪 | `lsh * 0.20`；速度 `uTime * 0.13` |
| 水底光紋 | `mix(0.16, 0.10, uTide)` |
| 燈影 | `lg * 0.75`；光柱長度 `mix(0.32, 1.3, …)` |

## 4. 效能

- 水底光紋只在深度 0–0.5 且非遠景的像素算（3 次迭代）；燈影只在夜晚／黃昏、5 盞燈、光柱範圍內計算；其餘是幾個 sin／value noise。沒有新增 draw call、貼圖或 render target。
- 正式 App 請在低階機器與五圖低幀率模式下確認幀時間；若需要降級，先關水底光紋，再關燈影，波光與陣風保留。

## 5. 還沒做、可以再討論的加強（未授權，需使用者同意）

- **漂浮落葉／蘆葦絮**：陣風後在水面留下幾片緩慢漂移的松針或花瓣，靠岸後消失。
- **晨霧貼水薄霧**：只在晨霧時段，水面上一層會被陣風吹散的低霧帶。
- **陣風的聲音**：陣風經過時，蘆葦沙沙聲短暫變大（需要音效素材，走既有試聽流程）。
- **蜻蜓點水**：白天蜻蜓偶爾點水留下一圈小漣漪（沿用現有漣漪陣列）。

## 6. 未決設計問題

- 舊版 REVIEW_2 要求「滿潮時閃光多約 40%」。新版在滿潮時改成**亮度略高但更稀、更細**，因為鏡面上的密集亮點會變成整齊點陣（使用者當初嫌像雪花）。請使用者試看確認這個取捨。
