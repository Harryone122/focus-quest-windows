## 1. 改了什麼

1. **平靜水面**：原本的風紋（五組交錯小波）、風紋明暗、星星倒影的晃動都乘上 `uSwell`，預設 0 ＝完全平靜的鏡面。旅人涉水的腳步漣漪、魚跳、丟石子、疊月橋合圓漣漪照舊（那是事件，不是波浪）。
2. **不要白點**：太陽方向的閃光亮點關掉（`col += 0.0 * gsp ...`；移植時直接刪掉整段 glint 計算）。
3. **飄動的雲**（湖面上看到的雲全是倒影，所以雲就在湖面 shader 裡）：
   - 一個固定風向：從蘆葦洲那側（畫面左）吹向東（畫面右），略往遠處；湖面 (u, v) 角度 0.22 rad。
   - 兩層：低層蓬鬆的雲每秒約 0.45 單位（大約一分半鐘橫越畫面）；高層薄雲條以 40% 的速度移動，兩層互相滑過，有遠近感。
   - 雲一邊飄一邊慢慢改變形狀（`uCloudEvo`，每秒 0.012），不會像一張圖平移。
   - 夜裡暗色雲慢慢滑過星空倒影，星星被雲蓋住。滿潮時淹水石台上也映著移動的雲（天空之境）。
   - 跟 `tAcc` 走：暫停時雲停住；減少動態效果時 1/4 速度。
4. **雲影**（使用者 2026-10-16「好，加雲影」）：用同一個雲場、同一個風向與速度，柔和的陰影掃過石台、蘆葦洲、松岩、亭子、旅人。只擋直射陽光（天光保留），所以陰影是柔和偏冷的灰，不會變黑；平時的物體影子在雲影裡跟著變淡，和真實一樣。白天最明顯（強度 0.45），晨霧／薄暮約 0.25，夜裡只剩很淡的月光雲影（0.12）。淺水底下的石面也一起變暗；湖面倒影本身不變暗。

5. **水波物理模擬**（使用者 2026-10-16：「白色圓圈太假」→「幫水波加上真實擴散的物理引擎，現在幾乎看不出有水波」）：湖面下有一張 640 × 512 的水面高度格（u −21..19、v −12..20，一格 0.0625 單位），在 GPU 上用波動方程每秒推進 24 步：每格被拉向四鄰平均、保有速度、每步損失一點能量。當下水位的乾地與靜止中的石環是牆，所以波會碰到石頭與岸邊反彈、彼此交疊、自然消散。魚跳（入水、落水各一次）、涉水每一步、丟石子、故事裡碰水都只是「往下壓一小碗水」，之後全交給模擬；涉水的旅人會拖出真實的尾波，繞過倒柱。湖面 shader 讀高度格的斜度：倒影跟著彎曲，波面依朝向變深／變淡，背向鏡頭的波峰微亮。白色圓環網格停用；水花顆粒縮小、半透明。跟 `tAcc` 走：暫停時凍結、減少動態效果時變慢。
   - **柔化（使用者 2026-10-16：「很喜歡，但有種突兀、生硬的感覺」）**：(1) 模擬改用 9 點模板（邊 4、角 1），圈保持圓形，不會偏方；(2) 淺水處波會變慢、自然消散（水深 0–0.06 之間速度與能量漸減），不再像撞牆一樣在岸邊硬停；(3) 魚的水花分 4 步慢慢壓下、腳步分 2 步，起始不再是一瞬間的凹洞；(4) 明暗改成柔和飽和曲線（`ripS / (0.55 + |ripS|)`），小波看得到、大波不會變成刺眼的亮暗帶，波峰光減半；斜度取樣放寬到 1.5 格，邊緣較柔。

## 2. 移植要點（給 Codex）

- Shader：新增 uniforms `uCloudA`、`uCloudB`（兩層已移動的距離，湖面單位）、`uCloudEvo`、`uCloudMore`、`uSwell`；`cloudD()` 的扭曲加上 `uCloudEvo`；`cp` 改用 `uCloudA`（取代原本 `0.15 * uTime` 的固定漂移）；新增高層雲 `hp/hd/hcov`。正式 App 可把 `uCloudMore` 固定 0、`uSwell` 固定 0 並刪掉相關乘項。
- JS：`cloudsUpdate()` 每幀把「速度 × 風向 × 動態時間差」累加成位移；用累加而不是 `速度 × uTime`，速度改變時雲才不會跳。在 `update()` 設定天色 uniforms 後呼叫。
- 雲影：場景建好後 `cloudShadowPatch()` 走訪所有 `MeshStandardMaterial`，在 `onBeforeCompile` 加入 `cloudShade()`（由 `vViewPosition` 與 `viewMatrix` 換算世界座標，取同一個雲場），並把 `lights_fragment_begin` 裡太陽（directional light）的 `directLight.color` 乘上它；會保留原本的 `onBeforeCompile`（潮痕帶、橋石紋），cache key 加 `|cloudShade`。之後才建立的材質不會套用；正式 App 若有延後建立的物件，請在建立後同樣處理。水面 shader 的 `bot` 也乘上同一個雲影（`uCSK`、`uCSAmt`）。
- 效能：每個受光像素多一次 5 層 value noise（雲影）；如果低階機器吃緊，可把 `csF` 降到 3 層，雲影形狀差別不大。
- 水波模擬：`SIM`（兩張 HalfFloat render target 輪替、一個全螢幕 quad 的波動方程 shader；地面高度沿用 `groundTex`）。`SIM.update()` 在 `update()` 最後呼叫（依 `tAcc` 固定步長，每幀最多 6 步）；`addRipple(u, v, maxR, life)` 保留原介面，改成 `SIM.drop()`。湖面 shader 新增 `uSim`、`uDom`、`uSimTx`、`uSimK`、`uFwd`，原本的 `uRip` 迴圈移除（uniform 可刪）。裝置不支援半精度浮點貼圖時 `SIM` 自動停用、湖面維持平靜。效能：每幀一到兩次 640 × 512 的小 pass，加上湖面每像素四次取樣。
- 只在原型：「雲的調整」面板（雲飄速度、雲量、雲形變化、水面波紋）與 `localStorage` 記憶。不要移植面板。

## 3. 調整參數

| 想要 | 改這裡 |
| --- | --- |
| 雲飄快／慢 | `CLOUD.speedA`（低層 0.45）、`CLOUD.speedB`（高層 0.18）；面板「雲飄速度」是倍率 |
| 風向 | `CLOUD.dir` 的角度 0.22（湖面 u/v，0 ＝ 畫面右） |
| 雲多／少 | 各時段 `PRE.*.cloudAmt`；面板「雲量」是加減值 |
| 形狀變化快慢 | `CLOUD.evo` 的 0.012；面板「雲形變化」是倍率 |
| 雲影深淺 | `WU.uCSK = (0.12 + 0.33 * cur.glint)`；面板「雲影」是倍率 |
| 水波明顯／不明顯 | `uSimK`（150）；倒影彎曲 `ripF += sl * 0.0032`；明暗 `rsS` 的 `0.62`／`0.34`；波峰光 `ripL * 0.09` |
| 水波傳多遠、多久消失 | 模擬 shader 的 `mix(0.80, 0.986, shallow)`（深水 0.986，越接近 1 傳越遠）；淺水範圍 `smoothstep(0.0, 0.06, dep)` |
| 水波速度 | `SIM` 的 `HZ`（24 步／秒，約每秒 1 單位） |
| 魚跳、腳步的力道 | `addRipple()` 裡的半徑與深度換算 |
| 想要一點點水紋 | 面板「水面波紋」(`uSwell`)，1 ＝ 舊版風紋 |
