# 倒影湖畔：兩個漲潮互動區域（2026-10-01）

使用者已接受方案並要求兩個都實作；本次交付為可操作網頁原型，測試完成後再處理正式 App 整合與打包。

## 畫面與旅人

- **浮葉小庭**：位於中央石庭東南側，中心 (12, −4.7)。退潮露出石庭、水槽石環與收攏花苞；水漲起來，葉片浮到水面並舒展，粉色／奶油色花朵展開。位置經調整以減少老松倒影遮蔽。新增水槽邊觀察／輕撥葉片動作，以及退潮石邊坐姿。
- **缺月石廊**：蘆葦洲東北側，中心 (−8, 6.5)。改為一座由 13 塊拱石、拱頂石、內緣線腳及階式基座組成的月洞遺構，搭配兩側殘牆與碎石。接縫設在 y=0.30，退潮露出底座，滿潮時半圓與倒影接成圓窗。旅人可以走到圓窗前看倒影。
- **石材修訂**：移除高低交錯的棋盤方塊，改為齊平、錯縫、有缺角的石板，加入裂隙、地衣與不規則護岸。沿用周圍石材的色系、潮痕及乾濕變色，並參照原石拱門加入頂點色風化與少量垂藤；滿潮時減弱水下鋪面的可見度。
- **夜間滿月**：湖面新增柔邊滿月倒影、淡光暈與月面明暗，水波讓邊緣及亮度緩慢、不規則地擾動；白天隱藏。共用水面動作時間，專注暫停時一起停止。
- 新增 5 個節點、5 條連線與 3 個互動點；全圖為 48 節點、51 邊、23 互動點。兩種潮位走同一條實體石路；旅人按示範排程器和燈截止時間選擇可容納的停留點。沒有新增獎勵或持久化規則。
- 預覽工具列新增「浮葉小庭」「缺月石廊」「回到全景」。近看按鈕只調整鏡頭，不開始計時；「試看漲潮」可以觀察水位變化。
