# Focus Quest 故事揭露與回收表

日期：2026-10-11。此檔含作者側秘密，不是玩家可見文案。現有細化故事逐事件列出；未製作地圖只列企畫已有的內容，不替它們發明已批准觸發條件。一般環境、休息與取物演出另見 [事件目錄](event-catalog.md)。

## 揭露原則與故事骨架

作者知道對方是某個可能未來的旅人自己。玩家前期只應看到熟悉的習慣、舊裝備、時間矛盾與「留給下一位」的照料；身份揭露留到真結局。地圖編號不是劇情閱讀順序。

建議審稿時使用以下層次；這是盤點分類，不是新增解鎖規則：

| 層次 | 玩家可合理知道 | 不宜由介面提前解釋 |
| --- | --- | --- |
| 起點 | 有人留下火與未完成筆記；記號可以被追尋 | 對方身份、時間迴圈全貌 |
| 地圖發現 | 不同地方有相似習慣／筆跡／物件，且有時間不對勁 | 把每個舊物直接稱作「未來的你」 |
| 重訪與對照 | 這些證據可能指向同一位旅人；照料工作可被接續 | 把推測寫成已確認的答案 |
| 相遇 | 對方認得筆記；領域有持續時間限制；有一頁不能照舊寫 | 要求缺頁或指定信物才能看一般相遇 |
| 真結局 | 身份、留下燈的意義、留白與選擇的關係獲得回收 | 把未蒐齊或停下工作稱為失敗 |

## 回收強度與調整方向

已完成最清楚的一條：**空苗盤 → 密刻度與告誡 → 帶苗種下 → 成長 → 玩家移植 → 疏刻度與再度空盤**。它具體、可看見，不必旁白解釋身份，可作為其他支線的品質參照。

有來源但回收未上線：井與熄燈 → h1；石碑刻度 → 10；石磬刻痕 → 05；水位刻片 → 06；聲音／十三響 → 09；蒼鯨 → 號角。

尚缺明確答案：站名牌後半磨掉的字、編號在船／櫃／提燈的共同含義、日期與時間的完整因果、告別如何在相遇重現。先定這些回收的用途，再增加新伏筆。

重複但可成立的三組母題：燈（援助與路）、一舊一新（時間與接續）、「從這裡開始」（開場入口）。要讓每次出現多提供一點不同知識；不要只換物件重複「有人來過」。
