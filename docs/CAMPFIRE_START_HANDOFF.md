# 旅程起點「霧岸營火」設計交接（Claude → Codex，2026-09-28，v2）

**狀態：2026-09-28 使用者已驗收 v2，可以開始移植。**

**v2 修改（使用者驗收意見）：**痕跡改成大型、看得出輪廓的物件；天色隨階段往日出推進，霧逐漸變薄；新痕跡只用光點標示，不再用文字標籤擋住旅人；旅人改回與其他地圖相同的樣式（寬尖帽、沒有五官、背上有鋪蓋）。

產品規格見企畫書 §48（本次新增）。這份文件只說明原型、錨點、演出時序與需要的狀態；**Claude 只交付設計**，正式場景模組、接線、實機 QA 與打包由 Codex 負責（`AGENT_WORKFLOW.md`）。

## 1. 交付物

| 項目 | 位置 |
| --- | --- |
| 可執行原型（Three r128，單檔） | `docs/prototypes/campfire-start.html`；Artifact「霧岸營火」 |
| 規格與故事 | 企畫書 §48；§46.8 首次相遇台詞已改；§47.3-2、§47.5-4 指向 §48 |

原型用大廳方案 A 的版面（左側特寫、右側玻璃面板、路線卡在特寫下方），面板與清單內容都是範例資料。右上角「原型控制」只用來切換痕跡階段、重播演出，不屬於遊戲 UI。

原型除錯用：`window.__campfire.setStage(0–5)`、`.setHover('bridge'|'steps'|null)`、`.depart()`、`.playReturn()`、`.advance(秒)`；設 `window.__hold = 1` 可停住 rAF，以固定步長檢查某一秒的畫面。網址 `#met0`、`#met1`、`#met2`、`#met3`、`#true` 直接開某個階段。

## 2. 什麼時候顯示

- 大廳 `phase === 'journey_start'`（新旅程、第一段還沒選）與 `phase === 'returned'`（最終領域相遇 → 回顧之後）時，特寫場景換成霧岸營火；其他階段仍是目前地圖的休息點。
- 右側面板、今天的清單、行囊、DepartureSheet 都沿用 LobbyA，不需要另做一套。面板第一行沿用 LobbyA 既有文字：`journey_start` 為「旅程的第一段」，`returned` 為「回到起點」。

## 3. 場景與錨點

原型在「鏡頭對齊的本地座標」內製作：`+x` 為畫面右、`+z` 朝向鏡頭，`y` 向上，單位與其他地圖相同。整個 root 轉 45°，所以鏡頭方位仍是 App 的 45°；移植時可以保留這個 root，也可以把座標轉到世界座標。

| 錨點 | 本地座標 (x, z) | 說明 |
| --- | --- | --- |
| `fire` | (0, 0) | 營火中心；石圈半徑 0.62；點光源在 y 0.6 |
| `seat_traveller` | (-0.62, -1.78) | 旅人坐的倒木；面向營火，臉朝鏡頭 |
| `seat_opposite` | (1.3, 1.36) | 對面的平石；坐在這裡的人背對鏡頭 |
| `seat_side_stone` | 平石右後方 0.55 / 0.45 | 錫杯放的位置 |
| `woodpile` | (2.25, 0.2) | 一開始就劈好、堆好的柴 |
| `crouch_light` | 由座位往營火方向，距火 0.95 | 借火時跪下的位置 |
| `signpost` | (0.35, -3.05) | 雙臂路標與紅布條（隨風） |
| `exit_bridge` | (-3.0, -4.75)，方向 (-0.53, -0.85) | 左：吊橋，長 11，中段下垂 |
| `exit_steps` | (3.1, -4.9)，方向 (0.55, -0.83) | 右：11 顆浮石，緩慢上下漂 |
| 目的地剪影 | 出口沿方向 17 單位，y 約 -0.6 至 -1.4 | 每張地圖一個遠景剪影（見 §6） |

鏡頭：
- 特寫：正交，仰角 = App 的 31° 再降 0.2 rad；看向 (0.1, 0.6, -0.7)，清晰區寬 8.4。
- 看向路：目標為出口往外 10 單位、y 0.2，寬 19；1.2 秒 smootherstep 緩動（與大廳 `setLobbyView` 相同）。
- 可拖曳偷看（偏航 ±0.5、俯仰 -0.15 至 0.25），放開後彈回。

光線以黎明前為基準，營火是主光。這個畫面**不跑日夜循環**，也沒有天氣；天色只隨痕跡階段改變（見 §4「天色」）。

## 4. 狀態與需要的資料

| 需要 | 用途 | 建議來源 |
| --- | --- | --- |
| `campfireStage` 0–5 | 對面空位的痕跡（累加顯示） | 由永久資料算出：0 = 從未相遇；1 = 相遇過、0 核心；2 = 1–3；3 = 4–6；4 = 7–9；5 = 已完成真結局 |
| `seenCampfireStage` | 最新一件痕跡是否已點開看過 | 與 `seenFindIds` 同一套已讀紀錄 |
| `playArrival` | 是否播「回到營火」 | 進入 `returned` 後第一次顯示時為真，播完回報已播 |
| 第一段兩條路 | 路線卡、出口對應 | 路線生成（Codex）；每條路線指定 `exit_bridge` 或 `exit_steps` |

痕跡階段 5（真結局後）取決於尚未定稿的真結局流程；在那之前後端只需要回傳 0–4。

痕跡物件（累加，較高階段包含較低階段的全部物件）：

| 階段 | 新出現的東西 | 位置（本地座標） | 點開後的文字 |
| --- | --- | --- | --- |
| 0 | 沒有痕跡，也不放標記；筆記留給第一次醒來的演出 | — | — |
| 1 | 劈柴的木樁，斧頭插在上面，旁邊散著新劈的柴 | (2.05, 1.95) | 對面多了一個劈柴的木樁，斧頭還插在上面。 |
| 2 | 火上的吊鉤架與吊壺（冒蒸氣）；側石上的錫杯 | 立柱 (0.98, 0.72)，吊壺懸在火的右前方 | 火上掛著一只吊壺，水快開了。石頭上的錫杯還是溫的。 |
| 3 | 柴堆旁的遮雨布（兩根柱子拉成斜頂，布邊隨風動）；平石上補過的毯子 | 遮雨布 x 2.75–3.85、z -1.05–0.85 | 有人在柴堆旁拉了一片遮雨布，繩結打得很仔細。 |
| 4 | 遮雨布下攤開的鋪蓋與一個舊背包；靠在平石邊的手杖，掛著同款但舊得多的提燈（熄著） | 鋪蓋 (3.25, -0.1)，背包 (2.95, 0.72) | 遮雨布下攤著一副鋪蓋。靠在石頭邊的提燈，和你的一模一樣，只是舊得多。 |
| 5 | 未來的旅人坐在平石上（同一套模型，灰色斗篷與帽子，背對鏡頭），他的提燈亮著 | 平石 | （不做點開物件） |

吊鉤架放在火的右前方，借火出發時旅人從左後方把提燈伸向火，兩者不會碰到。

**天色：**每個階段往日出推進一點，營火周圍的霧也逐步變薄（霧的不透明度 1.0 → 0.48）。原型的 `SKY` 陣列記錄每一階的天空漸層、霧色、半球光、太陽顏色與強度；切換時約 1.5 秒內緩動過去。階段 5（真結局後）是日出，陽光最暖、最強。

最新一件痕跡只在物件旁放一個琥珀色小光點（不放文字，避免擋住旅人）；滑過或鍵盤聚焦時才出現名稱，點開後是一句具體觀察，按「收好」關閉。看過之後光點變淡。

## 5. 互動與演出

**路線卡**（沿用 LobbyA 的 RouteCard）：滑過或鍵盤聚焦時鏡頭看向那條路；那條路上的霧從 0.92 淡到 0.3，露出目的地剪影；路上 5 個琥珀燈痕依序亮起（每個延遲 0.12 秒）；旅人轉頭看向出口。已選但沒有滑過的路線，燈痕保持 0.4。

**待機**：旅人坐在倒木上看筆記；約每 13 秒抬頭看火 4 秒。火焰閃動、火星上升、煙往右飄；草、蕨、樹冠、路標布條隨風擺動；浮石上下漂；霧慢慢橫移。

**借火出發**（按「開始專注」後，播放長度 5 秒，符合地圖離開演出的上限）：

| 時間（秒） | 動作 |
| --- | --- |
| 0–0.8 | 闔上筆記、站起；手杖從倒木邊移到右手（0.35–0.8） |
| 0.8–1.3 | 走到營火旁的 `crouch_light` |
| 1.3–1.6 | 跪下，手杖前傾，讓掛在杖頭的提燈懸在火上 |
| 1.75–2.05 | 一顆火星從火焰飛到提燈 |
| 2.05–2.4 | 提燈點亮（發光材質、點光源、光暈由 0 到 1）；營火同時旺一下 |
| 2.45–2.75 | 起身 |
| 2.75–5.0 | 沿路走到出口，踏上吊橋或第一顆浮石 |
| 3.7–5.0 | 霧蓋滿畫面，接到第一張地圖的入口 |

鏡頭：0–1.6 秒拉近到營火（寬 6.2），2.55 秒起往出口方向移動（寬 16，2.6 秒）。這段演出與其他出口演出相同，只負責畫面，不決定計時或存檔；中斷時直接顯示地圖入口。

**回到營火**（`returned` 第一次顯示，約 4 秒，之後恢復待機）：

| 時間（秒） | 動作 |
| --- | --- |
| 0–2.4 | 滿畫面的霧散開，旅人坐在倒木上低頭打盹 |
| 2.0–2.8 | 抬頭 |
| 2.9–3.6 | 轉頭看向對面座位 |
| 3.2–4.0 | 最新痕跡的標籤浮現 |

階段 1 以上回來時營火旺一下（有人添過柴）。

## 6. 目的地剪影

每張地圖需要一個低彩度的遠景剪影，放在出口外 17 單位的霧裡，只在滑過路線卡時露出來。原型做了兩個：

- 雲上遺庭：浮島、大樹、半截石拱。
- 苔痕驛站：台地、斜頂站房、月台、幾棵杉樹。

之後新增地圖時，一併提供它的剪影（沿用各自已驗收場景的標誌性輪廓即可）。

## 7. 未決的設計問題

1. 真結局後回到營火要做什麼（對話、是否繼續旅程）：等真結局腳本定案。原型的階段 5 只是示意。
2. 營火與出口的對應，例如兩條路是否固定一左一右，還是依路線特性決定：原型固定為左吊橋、右浮石。
3. 旅人模型：v2 已改回與其他地圖相同（使用者決定），不加五官、不改帽子。§47.5 第 5 項（大廳特寫時帽簷遮臉）維持原樣，不另外處理。
4. 收藏室入口：依 §50，大廳與營火都要在旅人身邊放一個看得到的行李，按「收藏室」時鏡頭推進行李。原型的行李在倒木左側 (-1.95, -1.25)；推進演出依 `COLLECTION_ROOM_HANDOFF.md`，這個原型還沒做。
