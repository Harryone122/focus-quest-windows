# App 外殼：導覽列與功能面板設計交接（Claude → Codex，2026-09-28）

規格見企畫書 §51（本次新增）。這份文件只說明原型、版面、互動和需要的資料；**Claude 只交付設計**，正式實作、接線、實機 QA 與打包由 Codex 負責（`AGENT_WORKFLOW.md`）。

## 1. 為什麼要改

目前只有「今天」（大廳）和「世界」（收藏室）底下有 3D 場景。切到「任務」「紀錄」「設定」時，整頁換成舊版實心頁面，左側導覽也變回深藍色，和大廳、收藏室的玻璃介面不一致。此外，導覽底部的「旅程留下的痕跡／檔案館正在甦醒」是依累計專注時間分階段的舊世界狀態，§50 已經廢除。

| 項目 | 位置 |

原型的背景是兩張靜態截圖（霧岸營火、收藏室），只用來表現「場景在後面」；大廳面板與路線卡是方案 A 的簡化複製，只示意「全部事項」的入口。網址 `#log`、`#settings`、`#all`、`#room` 可以直接開對應的狀態；`window.__shell.go('log')` 可以切換。所有資料都是範例。

## 3. 原則

1. **場景永遠在後面，不換頁。** 「今天」與「收藏室」是兩個場景；「紀錄」「設定」「全部事項」是蓋在目前場景上的玻璃面板。整個 App 只剩一種介面語言。
2. **導覽列永遠是玻璃**，因為它底下一定有場景。
3. **每個面板只放用得到的東西**，不放裝飾性的圖騰、英文標語或大數字牆。

## 4. 導覽列

- 浮在左邊的玻璃直條：寬 80、上下左留 16、圓角 18。內容從上到下：提燈標誌、四個按鈕、底部的「今天 N 分鐘」。
- 四個按鈕：**今天、收藏室、紀錄、設定**（圖示＋底下的字，字級 11.5）。
  - 目前所在：琥珀色字與圖示、淡琥珀底、左側一條 3px 琥珀直線，並設定 `aria-current="page"`。
  - 收藏室有新東西時（新核心或托盤裡有新線索），圖示右上角出現琥珀小點，也就是現在 `collectionHasNew` 的那個點；進入收藏室後消失。
  - 在已經打開的面板上再按一次同一個按鈕，關掉面板、回到今天。
- 拿掉：「任務」按鈕（併入全部事項，見第 7 節）、品牌文字「Focus Quest／霧中旅程」、底部的世界階段卡片。
- 底部「今天 45 分鐘」＝今天累計的有效專注分鐘數，只顯示，不能點。
- 大廳右上角的「收藏室」按鈕（`la-collection`）移除，改由導覽列進入。收藏室裡的「回大廳」按鈕也可以移除，導覽列的「今天」就是回大廳。
- 視窗寬度 ≤ 760 時，導覽改成底部的橫向玻璃條（四格），提燈標誌與今天分鐘數隱藏。

**建議的 View 改法：**`type View = 'today' | 'collection' | 'log' | 'settings'`，另加一個大廳內的面板狀態 `sheet: null | 'all'`。舊的 `library`、`journey`、`insights` 網址（`?view=`、`collection-`）改成對應到新值，避免舊捷徑壞掉。

## 5. 面板（紀錄、設定、全部事項共用）

- 位置：導覽列右邊，上下留 16，寬 `min(620px, 剩餘寬度)`，圓角 18。
- 樣式：比一般玻璃深一點，`rgba(18, 24, 30, 0.62)` 加 20px 模糊；頂部是一行小標籤＋襯線大標題（24px，字距 0.14em）＋右上角關閉「×」；內容可以捲動。
- **打開時場景退後**：場景畫面 `blur(10px) brightness(0.55) saturate(0.85)` 並放大 1.04，0.45 秒；大廳自己的面板、路線卡、旅程標籤同時淡出（0.35 秒）。面板從左邊 14px 處滑入並淡入（0.35 秒）。
  - App 裡建議直接對場景的 canvas 加 CSS `filter`（Electron 裡效果穩定），面板本身用半透明底色即可，不必再讓場景畫玻璃。
  - 面板打開時，場景可以降低幀率或暫停非必要的動畫，省電。
- 關閉：右上角 ×、按 Esc、點面板外的模糊場景、再按一次導覽列上同一個按鈕。關閉後回到「今天」，場景恢復清晰。
- Focus 進行中不開放這些面板，沿用目前的規則。
- 減少動態時：沒有模糊、放大、滑入，直接切換。

## 6. 紀錄

「只看做了什麼，不評價你這個人。」內容依序：

1. **三個數字**：今天（分鐘）、這 7 天（小時＋分鐘）、這 7 天完成的事（件）。只有這三個。
2. **近 14 天的專注**：一張長條圖（每天分鐘數）。今天是琥珀色，其他天是淡青；縱軸 0／1h／2h（依最大值調整）；橫軸隔一天標一次日期，最後一格寫「今天」；右上角寫「平均每天 N 分鐘」；滑過長條顯示「月/日 · N 分鐘」。
3. **最近的專注**：最近 5 次。每列：事項名稱、時間與當時所在的地圖、分鐘數，最後是「✓ 完成」（淡青）或「還沒做完」（灰，不用紅色）。
4. **走過的旅程**：每一趟一列：第幾趟、日期範圍（進行中寫「走到第 N 段」）、五段地圖的路線（`雲上遺庭 → 苔痕驛站 → …`），以及這趟取得的核心。

拿掉：舊版的「OBSERVATION LOG」「FOCUS TRACE」等英文裝飾、「14 DAYS」印章、「被攔下的分心」統計。

需要的資料：每天有效專注分鐘（14 天）、最近的專注（事項、開始時間、分鐘、地圖、是否完成）、旅程歷史（每趟日期、造訪地圖序列、取得的核心）。

## 7. 全部事項（取代「任務」分頁）

從大廳清單標題右邊的「全部事項 ›」打開（琥珀色小連結）。它屬於「今天」，所以導覽列仍標在「今天」。

1. **昨天沒做完**（有才出現）：一條琥珀邊框的橫幅，列出事項名稱，按鈕「全部移到今天」、「刪除」。刪除要在頁面內再確認一次（不用 `window.confirm`）。這和大廳清單現有的「昨天沒做完」分頁是同一份資料。
2. **新增一件事**：輸入框＋「加入」，下面三選一：「放到今天」（加到今天清單最後）、「之後再做」、「每週例行」。選每週例行時出現星期一到日的圓形開關，預設一到五。
3. **今天的清單**：唯讀的順序（順序仍在大廳調整），一般事項可以按「之後再做」移出今天；例行事項標 ↻。
4. **之後再做**：現有的「暫放」事項（原任務庫的 `backlog`），顯示暫放日期，按鈕「放到今天」與刪除「×」。
5. **每週例行**：每個例行事項一列，後面是星期一到日的開關，可以直接改；刪除「×」。
6. **最近完成**：14 天內完成的事，刪除線，顯示日期，按鈕「再做一次」（加到今天清單最後）。

原任務庫裡的「新增任務精靈」與任務卡片可以一併退役；新增只保留這個輸入列和大廳清單底下原本的「丟一件事進來，按 Enter」。

## 8. 設定

一頁清單，分三組，改了就生效：

| 組 | 列 | 控制 |
| --- | --- | --- |
| 專注 | 提醒 | 三段切換：安靜／溫和／有節奏；下方一句說明隨選項變 |
| 專注 | 晚上整理今天的時間 | 只在「有節奏」時出現；時間輸入 |
| 專注 | 開始前確認手機放遠 | 開關 |
| 旅人 | 斗篷 | 三個色票：午夜藍、墨綠、暗紫 |
| 旅人 | 提燈的光 | 三個色票：琥珀、星青、紙白 |
| 資料（只存在這台電腦） | 備份／還原／匿名使用紀錄 | 按鈕；還原要在頁面內再確認一次 |

最底下一行小字寫版本號。拿掉舊版的羅盤圖騰與圖示化的按鈕。
