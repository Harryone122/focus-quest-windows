## 已接上

- 導覽固定為玻璃直條，四項為今天／收藏室／紀錄／設定。移除任務分頁、品牌文字、累計專注世界狀態卡、大廳右上角收藏室按鈕，收藏室原「回大廳」按鈕隱藏。底部顯示今天已結束專注的有效分鐘；收藏室新發現提示在導覽圖示。進入收藏室後提示消失，若再得到新核心或托盤線索會再亮起。
- 紀錄、設定、全部事項共用一個覆蓋場景的玻璃面板。場景模糊／變暗／放大，大廳 UI 淡出；×、Esc、點場景、再按同一個導覽按鈕可關閉。從收藏室開面板時收藏室仍在後方；關閉回今天。減少動態時不做模糊、放大、滑入。Focus 與回顧期間沿用全畫面流程，不開面板。
- 紀錄：今日／七天有效專注與七天完成事項、14 日圖、最近五次專注、所有旅程及其核心。數據由 SQLite 投影到快照的 `activityLog`，不受舊版「只取最近 30 次專注」限制。
- 設定：提醒、結構化提醒時間、手機放遠、斗篷／提燈顏色、備份／還原／匿名紀錄。還原使用頁內確認，並顯示 `package.json` 的版本。
- 全部事項：昨日未完成、標題輸入與三種放置方式、今天唯讀順序、暫放事項、例行星期選擇、14 天內完成事項的再做一次。大廳的「全部事項 ›」是入口；實際操作沿用現有 IPC，沒有改 §47.4 的順序、換日與例行產生規則。
- 舊入口：`library`→今天的全部事項、`journey` 與 `collection-*`→收藏室、`insights`→紀錄；`?view=` 同樣支援舊值。

## 資料與相容性

- `AppSnapshot.activityLog`：`days`（14 天有效秒數／完成件數）、`sessions`（最近五次，含地圖與完成狀態）、`journeys`（路線與核心）、`recentlyCompleted`（14 天）。全部由主程序唯讀查詢產生。
- `ListTask.parkedAt` 記錄真正移入「之後再做」的時間；從暫放回今天會清空。舊存檔沒有此欄時，以最後修改時間作一次性近似回填。備份格式升至 v11，v1–v10 仍可匯入。新增了舊 v10 匯入測試。
- 收藏室新提示的「已進入」狀態是該隔離資料夾的 localStorage UI 標記；核心、線索及所有規則仍由 SQLite 快照決定。

## 驗證

- `npm run build`：型別檢查、141 項 Vitest、Electron renderer/main/preload 編譯皆通過。
- `scripts/qa-app-shell.cjs`：以原使用者存檔的 SQLite 線上備份放在 `%TEMP%\focusquest-shell-v51-qa-20260929`，實機 Electron 使用獨立資料夾，QA 視窗移至副螢幕。原存檔有一筆正在進行的專注；**只在 QA 副本**將該筆標成已結束，正式存檔沒有修改。驗證四個導覽、全部事項新增實際寫入、三面板、四種關閉方式、舊網址重新開啟、收藏室留在面板後方，console 無程式錯誤。
