## 2. 戶外場景

1. **地形與鏡頭**：天坑＋雲海、左側河流與大瀑布、右上採石切口。鏡頭固定正交，方位 45°、仰角 31°，home 目標 (5.0, −0.5, 5.0)，畫面高 22.5（16:9）；拖曳可轉 ±1.1、上 0.5／下 0.12，放開彈回。地形是原型裡的程序生成（`H(x,z)`），請照原型的函式與上色規則移植，不要換成別的噪聲。
2. **畫面重心＝懸崖鐘樓**（`BELL` 模組）：懸造舞台、紅漆欄杆、四柱亭子、大梵鐘、撞木（物理擺動，碰到鐘才發聲）、前簷兩盞燈籠、東側吊橋。

3. **共鳴洞洞口（v9 修正，請照做，不要退回舊作法）**：
   - 拱形洞口外圍是**一整片相連的岩面**（三圈，沒有縫），所有面單面、法線朝外；隧道深 1 單位，法線朝內，顏色往裡漸暗，盡頭用**不透光的深色底**封住。

## 3. 洞內場景（v9 新做）

- 在原型裡是 `grotto` 群組（世界座標 x+400，JSON 的洞內座標是群組本地座標）。水面 y = 0。鏡頭同樣 45°／31°，home (2.0, 0.2, 1.7)，畫面高 15；**洞內拖曳範圍 ±0.55、上 0.35**（再大會沿洞壁內側看出去，使用者會看到不自然的黑牆）。
- **洞壁**：後方一整條連續的帶狀網格（112°→338°，越往兩側越低、頂緣不規則），兩端用大石堆收掉；前方只有低矮岩石。四周 CSS 暗角。
- **水面**：真正的平面倒影（`renderReflection()`：鏡像正交相機＋全域剪裁平面，畫到半解析度 render target）。倒影時隱藏水面、光柱、洞頂的根和楓枝、石壇暖光暈。漣漪只在聲音和落葉時出現（最多 8 個）。
- **光**：一盞從後上方岩縫照向石壇的 SpotLight（有陰影）、跟著鏡頭轉的柔邊光柱 shader（3 片）、水面上的暖光圈、石壇暖光暈、兩盞補光。光柱顏色跟洞外時間：白天暖白，夜裡冷藍、變暗。
- **蓮與秋葉**：約 70 片蓮葉（避開路線與石壇）、白蓮約一半淡淡發光、花苞；46 片漂浮楓葉跟著慢水流轉，會被氣波推開；每 10–18 秒一片楓葉從光柱落下、落水起漣漪。
- **霧與光點**：水面低霧（16 個 sprite）；300 顆光點（光柱內偏暖、其他偏冷藍），會被氣波推開，取得核心時被吸向石頭。
- **路線**：節點與三條路線在 JSON `cave.nodes`／`cave.routes`：進洞 `E0→E1→L0→B1→B2→J`、往石壇 `J→B3→I0→A0→S1→S1b→S2→S2b→ST`、往封住的牆 `J→W1→W2→W3→WL`。節點第三個值是腳下高度（棧道 0.32、石壇兩層 0.55／0.76）。
- **石壇**：八角兩層、兩級台階、注連繩只圍三面（開口朝台階）、紙垂、兩盞小石燈籠、蓮瓣石座；藏聲石在 (−2.5, 1.72, −2.5)。
- **封住的牆**：嵌在洞壁裡的方石板（縮放 0.8）＋框石＋上楣石，前面有石台。
- **藏聲石每 8 秒低鳴**：淡藍球形氣波（被水面切掉）、水面漣漪、藍孔閃一下、發光白蓮變亮。取得核心後不再低鳴，石座空著。

## 4. 探索中進洞：聽回音（v10，使用者要求洞內不要只在拿核心時才進去）

**理由**：藏聲石會把山谷裡的聲音留住，過一會兒再放出來。這也解釋首訪線索「敲了一下，回來的是兩個音」：第二個音就是洞裡的石頭還回來的。

**流程**：
1. 這一趟探索裡，旅人做了會發聲的互動（1 石磬、3 回音巨石、5 敲鐘、6 風孔岩、13 聲壁）。
2. 4 秒後的下一次洞口低鳴，改成那個聲音的回音（暖色氣波＋一圈冷色），**一趟只放一次**；狀態文字「共鳴洞的洞口傳出一聲回音，像剛才的○○。」
3. 之後旅人挑下一個地點時，**60%** 選 12 共鳴洞（要先通過時間預算）。
4. 到洞口：沿隧道中線走進黑暗（`caveMouth.axisOutside → axisInside`），0.7 秒淡出。
5. 洞內：從 E1 走 `E1→L0→B1→B2→J`，在岔口面向石壇聽（`listen` 姿勢）；1 秒後石頭放出那個聲音（石磬＝兩個音、巨石＝一聲加往內收的回音、鐘＝大型暖色氣波、風孔岩＝三聲低嗚、聲壁＝一聲悶響；原型 `CAVE.ECHO`），停 7 秒後原路走回 E1。
6. 0.7 秒淡出 → 戶外：旅人從洞內點沿中線走出洞口，接著照常閒晃。
- 他**不跨進注連繩**、不碰石頭。拿核心時石頭才會「回應」他（核心事件的演出）。

**節奏規則（請照做，使用者要求不能喧賓奪主）**：
- 每趟探索**最多進洞一次**。這趟如果排了核心事件或第二次造訪事件，那就是這趟的進洞，不再另外聽回音。
- 必須先在這一趟發出過聲音。
- 探索開始 300 秒內不進；五盞燈點完、休息後不進。
- 時間預算（有效秒）：`走到洞口 + 200（洞內） + 從洞口走到下一盞燈 + 60 < 下一盞燈到期 − 現在`。**選地點時檢查一次、走到洞口時再檢查一次**；第二次不通過就只在洞口聽（原本 12 號的 `listen` 演出）。
- 洞內時間照常走（燈、日夜不停）；暫停時洞內也暫停。專注 HUD 不切換（原型用 `inCaveVisit` 只加暗角）。
- **純視覺，沒有獎勵、線索或永久進度**。
- 抽選、排程、存檔由後端決定；原型的隨機只是示意。動畫失敗或中斷時，以已保存結果為準。

## 8A. 營火遠景剪影（Claude，2026-10-13 新增）

### 造型

- 浮島：石台、倒錐、右後方岩丘，岩丘正面有共鳴洞的暗色洞口。
- 鐘樓：懸在浮島前緣外，四周有紅欄杆。屋頂是入母屋造：四角起翹的下層屋簷，加上白色妻壁朝向鏡頭的切妻。屋簷下掛兩盞暖色燈籠，中間吊梵鐘，南側吊撞木。
- 木柱與木橋：平台下 3×3 根木柱和橫撐，一路往下沒入剪影自帶的霧團。吊橋從平台東側接回浮島。
- 瀑布：一條河流過島面，從左緣落下。水幕慢慢往下流，越往下越淡。
- 樹：楓紅、橙、銀杏黃為主，帶一點自發光，在黎明前的暗光裡也看得出顏色。杉樹用深灰綠。**只有這個剪影有彩色**，這是使用者同意的例外。

### 響一聲（時間以 `S.hoverT` 計，也就是滑過路線卡後的秒數）

| 時間 | 演出 |
| --- | --- |
| 0.6–1.25 秒 | 撞木慢慢往後拉（鏡頭正在轉向那條路，霧正在散開） |
| 1.35 秒 | 撞木放開敲鐘。一道暖白色的球形氣波從鐘的位置往外擴散，3.4 秒內擴到半徑約 6.9，只有邊緣淡淡發亮。0.38 秒後再擴散一道較小、較淡的氣波。梵鐘微微擺動，約 6 秒停下 |
| 敲鐘時 | 呼叫 `window.__campfireOnSilhouette('area-05-echo-quarry', 'bell')`，給音效接線用 |

- 每次滑過只響一次，一直停在卡片上也不會再響。離開卡片（`hoverT` 回到 0）後重新上膛，下次滑過才會再響。
- 只有滑過路線卡才會響。已選但沒有滑過的路線、出發演出、回到營火，都不響。
