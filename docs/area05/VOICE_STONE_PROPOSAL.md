# 藏聲石取得演出建議（2026-10-11，待使用者討論）

這是 Codex 讀完完整核心企畫書後的建議，不是已批准的劇本；試玩中的核心演出尚未依本提案改寫。

## 主軸：聽見一段不屬於剛才的回音

企畫 §46.6 的核心是「保存不完整的告別」，§46.8 要求前期不直接揭露說話者；§48 讓火、提燈與再次相遇相連。現有試玩側重急促低鳴、整洞藍光、石頭縮進行李，能表達取得物品，還缺少那段告別的情緒。

建議讓普通回音教會玩家「這裡會還回剛才的聲音」，核心事件再打破這個預期：石頭裡傳出的話，是旅人沒有說過、還不知道指向誰的告別。核心可以先於第二造訪取得，因此演出不能假設已聽過「柴都濕了」，也不要求此前一定進過洞。

## 建議順序

1. 後端依既有燈段 5%／第五次保底判定並保存取得；演出安排旅人從戶外走進洞口，沿現有路線抵達石壇。聲音、鐘響次數或持有風哨都不新增成取得條件。
2. 旅人放慢腳步，在石壇前停下。石頭先低鳴一次，水面有一道很淡的波紋；旅人側頭聽，留約兩秒安靜。
3. 孔裡傳出一小段人聲，像話的尾端被截斷。可討論的台詞草案：「……如果你先到了，……」之後只有一次呼吸，下一句沒有傳回來。確切告別內容應與最終相遇一起定稿；不用取得說明直接解釋說話者，也不把「柴都濕了」移來當核心台詞。
4. 旅人靠近、伸手察看，石頭才浮起。保留這次核心藍光辨識，但建議壓低閃幕、改成孔緣細藍光和一次沿水面擴開的藍色波紋；不用越來越急的三連鳴。石頭緩緩縮小，停在手邊，再收進行李。聆聽到收起約 12–15 秒，實際行走時間另計。
5. 旅人再看一次空石座，沿原路走回戶外。之後再訪保留空座；收藏與線索的文字只記錄聽到的具體片段，解讀留給後續。

普通聽回音依然只有畫面、每趟最多一次且須符合完整返燈預算，不發核心、不發新獎勵。核心事件不必先看過普通回音才能成立。音檔由使用者提供；目前不自行合成。

## 取得與「看懂」分開

取得時只知道它留住一段話。之後在最終相遇聽見同樣的停頓或話頭，留下一條永久相遇紀錄，再讓收藏室顯示「看懂了一些」，會比拿到核心當下就解開更有回收感。若希望較早解讀，也可另設取得後重訪空石座的永久線索，需另外確認。

礦車中的大型多孔石頭是 §50 的展示初稿，Area 05 交接仍把展示和解讀條件列為未定；本提案不自行批准展示方式、不改 `CORE_UNDERSTANDING_CLUES`。解讀只能讀永久紀錄，不依本趟有沒有帶信物。
