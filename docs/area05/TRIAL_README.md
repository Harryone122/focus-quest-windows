## 開啟與操作

雙擊桌面 **「藏聲秋谷－Area 05 試玩」**，或執行 `scripts/try-echo-quarry.cmd`。在有第二螢幕時使用第二螢幕；入口使用獨立暫存資料夾，不匯入正式 main、不開啟玩家資料庫。

- 探索自動開始；可選正常、6／20／60 倍，隨時暫停或繼續。五燈依有效時間亮，不等旅人動畫完成。
- 拖曳可窺看角度，放開回 home；洞內保留較小的拖曳範圍。
- 展開「逐段試看」：岩壁裡的聲音、取得藏聲石、銅製風哨，以及山風石歌。核心與岩壁事件都從戶外走到洞口、走進隧道、淡出、走洞內路線，再按原路返回戶外。
- 「聽回音的探索」開始獨立場景：20:05、兩盞燈已亮、旅人在石磬架旁，速度回到 6 倍。先實際敲石磬，之後仍經 60% 抽選與兩次時間預算檢查，**不強制進洞**。其他探索也會自然觸發。
- 「走去休息」跳到五燈完成，旅人走去觀景平台；洞內演出尚未結束時請先等他出洞。
- 核心演出後石座會空著，同一視窗的後續探索／岩壁事件保留空石座。關閉重開為全新的獨立試玩；本階段不提供正式專注中斷恢復。

## 已移植與工程調整

`src/renderer/src/echoQuarry/echoQuarryScene.js` 從原型的程序地形、物件、旅人、A*、洞口、球形氣波、日夜、平面倒影、洞壁、蓮池與事件移植。本機沿用 three.js r128，不依賴 CDN 或線上字型。原型原檔、JSON、設計紀錄、10 張設計預覽及原 QA 腳本沒有改寫。

原型右下／洞內面板、QA URL 參數及 `window.__quarry` 不移植。獨立試玩介面另建；其測試控制器只在此入口提供。移植可由 `python scripts/port-echo-quarry.py` 重現，再由 `node node_modules/vite/bin/vite.js build --config scripts/echo-quarry-tester.vite.mjs` 建立離線頁。

回音與風的抽選使用 Electron main 的獨立權威狀態，結果在暫存 `exploration.json` 中保存；當狀態改變時才寫檔。回音要求本趟發聲、洞口只回一次、每趟最多一次、300 秒後、五燈／休息前、核心或第二造訪預留時不另排回音。選地點與抵達洞口都使用 `走到洞口 + 200 + 洞口到下一盞燈 + 60 < 下一燈到期 - 現在`。已將返燈距離從**洞口**計算，避免原型用當前旅人位置造成估算偏差。

暫停凍結戶外／洞內移動、時鐘、光線、波紋、粒子、轉場和字幕時長。風每 240 秒有效時間擲 8%，第一次 13 下；不寫入尚未確認的山風線索。特殊發現／事件按鈕只重播畫面，**不發獎、不新增永久線索**。
