# Copy Style

## Voice

Focus Quest copy is short, natural, restrained, and clear, with a light sense of place. It may name a concrete sound, object, room, or change. It should not try to make every action profound.

The desired tone is atmospheric without performing wisdom.

## Prefer

- 「選一條路」
- 「開始探索」
- 「繼續探索」
- 「已保存進度」
- 「尚未發現」
- 「星盤的一部分重新亮起。」
- 「你在抽屜裡找到一封沒有寄出的信。」
- 「前方的走廊比想像中安靜。」

These lines work because they describe an action, object, or observable change.

## Avoid

- 「每一次專注都會成為星光」
- 「你的努力終將照亮前路」
- 「讓靈魂在寂靜中前行」

[DO NOT IMPLEMENT] Motivational slogans, fake literary depth, life philosophy, abstract encouragement, or generic AI-poetic filler. Do not force a reflective sentence onto every screen.

## Functional copy rules

- State the action directly: 「開始探索」, not a metaphor that hides the button's effect.
- Distinguish selection from commitment: 「選擇路線」 versus 「開始探索」.
- Distinguish saved partial progress: 「已保存 18 分鐘」 or equivalent concrete progress.
- Name irreversible actions plainly: delete, end session, import backup, or mark task complete.
- Describe recovery honestly. Do not imply an exact animation replay when only the timer checkpoint is restored.
- Do not call 25/50/90-minute routes easy/normal/hard or common/rare/legendary.
- A blocked outcome is a neutral record, not failure copy.
- An incomplete day is not a loss.

## Screen budgets

- Page title: preferably 2–6 Chinese characters.
- Primary button: preferably 2–4 characters when unambiguous.
- Supporting copy: at most one short sentence per ordinary screen; zero is acceptable.
- Event copy: one concrete observation plus the actual choice or result.
- Avoid decorative English micro-labels unless they belong to a physical world object.

## Product terms

Use these terms consistently:

| Concept | Preferred wording |
| --- | --- |
| Today's primary real task | Main Quest / 主線 |
| One day's roguelite structure | Daily Expedition / 當日遠征 |
| A route destination | Node / 節點 or a concrete place name |
| Work interval | Focus Session / 專注 |
| Saved incomplete node | Partial / 已保存進度 |
| Post-session screen | Debrief / 探索紀錄 or a concise localized equivalent |
| Permanent hub | 星光檔案館 |
| Safe end of day | End Expedition / 結束遠征 or Return to Archive / 返回檔案館 |

Do not expose internal state identifiers such as `awaiting_reward` to users.
