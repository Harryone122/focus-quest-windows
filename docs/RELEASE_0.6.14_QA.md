# 0.6.14：苔石穿模與跨地圖霧幕修正

2026-09-27。依使用者的兩張 Windows 截圖修正。

## 變更

- 苔石原事件站位在石頭的體積內，往舊道標的直線也穿過石頭。移動苔石／舊道標站位，路線繞石頭北側的陸地；不走南側溪床。模型、事件、獎勵保持原設計。
- `area-02-moss-station.scene.json` 同時供後端排程與前端讀取，繞路長度納入時間預算。既有節點、事件與邊的 ID 不變，存檔不需遷移。
- 跨圖離開完成後保留來源畫面的最後一幀，目的地在透明圖層內以正常尺寸建立。兩幀實際繪製完成（包含初始 shader 與玻璃介面）才以 300 ms 淡入，350 ms 後釋放來源 renderer。
- 跨圖來源不再升起全畫面白霧；抵達不再重播白霧。這修正載入期間的空白／遮蔽，並不宣稱所有硬體都能瞬間完成新場景編譯。
- 來源離開完成後不再重新初始化或繪製旅人。暫停建立的場景也會完成最初兩幀，再保持專注時間凍結。
- 計時、燈、事件及獎勵仍由後端決定，沒有依動畫完成回呼計算。

## 驗證

- `npm run dist -- --config.directories.output=release-v0.6.14` 包含型別檢查、18 個測試檔／132 個測試與正式 build。
- 原 60 種子、300 次路燈期限測試通過，包含天氣變化及特殊發現。
- 新增路徑回歸測試：同正式 Three 曲線，三段鄰近路徑的正反向各採樣 201 點，含站位，避開石頭外包絡與旅人寬度；後端距離涵蓋曲線長度。
- `scripts/qa-moss-boulder.cjs` 使用正式場景在 Windows WebGL 繪製靠近、觸摸苔石、繞路、閱讀道標、回程；人工檢視截圖。旅人站在陸地上，沒有穿入苔石或溪床。證據：`previews/area02-fixes-qa/boulder/`。
- `scripts/qa-area02-port.cjs` 使用實際主程式、preload、SQLite、正式路線及介面操作，測試四個出口。新版檢查目的地已畫好才顯示、來源保留到淡入後、來源沒有不透明霧幕；不再只以新 canvas 存在認定切圖完成。
- 所有自動化遊戲測試使用暫存存檔。真實使用者存檔只於切換版本前備份及唯讀核對。

## 範圍

兩張地圖依然同時可選。沒有改動隨機獎勵、天氣算法、使用者專注紀錄或原型 HTML。0.6.13 已記錄的雲上遺庭「暫停重開的玻璃構圖」不屬於這次兩項修正；保存狀態仍有回歸驗證。
