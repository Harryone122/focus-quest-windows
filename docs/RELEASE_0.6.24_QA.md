# Focus Quest 0.6.24 — 倒影湖畔整合

日期：2026-10-03。使用者要求接手 Claude 第三張地圖、連接後端、檢查問題並一起打包音效；此為新的整合授權，取代此前 Area 03 音效「先不接遊戲」的等待狀態。

## 本次範圍

- 依 `area03/CODEX_HANDOFF.md` 移植已驗收的第 1–4 段、3C、標尺和 Opus 收尾，沿用原型的湖面、反射、潮汐、橋洞、旅人、杯子、坐姿、離開路線。40 個一般事件、4 個特殊發現呈現（3 件物品）、5 種休息、2 個出口。
- 新增 `shared/area03.ts`；本機後端保存每次探索的潮汐種子、逐路段行走、事件意圖、已處理發現、冷卻時間、筆記與世界記憶。五燈每 600 有效秒亮；原有不足 5 分鐘不保存探索進度的規則保留。
- 沿用共用獎勵：第 1–4 燈必得水位刻片／背銀鏡片之一；湖鏡每燈独立 5%、第五次造訪保底、立即永久保存。來源及動畫失敗不影響結果；既有 backup v13 表格可保存新地圖，未新增必要資料表。
- 地圖加入後續兩路候選、未取得核心優先規則、大廳投影、兩出口與跨圖離開、收藏室 m03 展示。既有營火第一趟兩路外觀保留；若前两圖核心都已取得而湖鏡未取得，初始選路也會包含湖畔。
- 音效：28 個來源隨程式打包。26 份先前修正版 WAV，另兩份音樂為原錄音副本；未採用重新移調／編排的候選，沒有新增合成。風、水拍、潮汐、日鳥／夜蟲與動作依場景時機播放，環境／音樂使用既有設定。翻杯、倒茶、放杯、拾取及核心聲以演出進度觸發；暫停同步停止、恢復不補播過期提示。
- 同步五份文件中的地圖名稱。第 5 段故事、信物故事、線索及橋名決策仍待設計，沒有自行實作。

## 修正與限制

- 原型特殊發現只有示範時長，正式程式補入旅程信物 35–60 秒、核心 80–110 秒。
- 補齊湖畔出口及保存的來源狀態，低幀率下離開仍以真實暫停感知時間走 5 秒，不累積封頂幀時差而拖長。
- 移除素材標記的動態 eval，避免正式壓縮改名後找不到材質；補齊場景交接後的 ResizeObserver、卸載空 host 防護，以及反射目標／材質／陰影資源清理。
- 暫停時頭部倒影歷史不再持續追加重複時間；倒影延遲使用有效秒而非幀數。
- 一般場景約 239–252 draws（包括正式玻璃約 4 次繪製）；原設計的核心額外反射例外保留。沒有隱藏亭子屋頂或場景物件。
- 自動測試／解碼和截圖不能代替使用者對新音場音量及音色的聽感驗收。
